## 一句话结论

**服务不动**：ASR/TTS/分人/准入继续归 Python，且按红线不接收 LLM、资产与 UI。
**能力长在 App**：采集、混音、回声消除、播放、浮层、热键、LLM 编排、SQLite 资产全部属于 macOS 原生层；
其中唯一需要新增进程的是系统音频的 tap helper（`T1` 已裁决：App 内 XPC service）。

**设备按功能启用、功能离开释放（用户 2026-09-18 裁决，R4）**：App 不做常占——空闲时不打开麦克风、不建
系统录音 tap、不跑音频引擎；权限按需申请（系统录音只在第一次选「本机音频」时才要）。时点、原型与五条
可观测验收判据见正文 §3.5 与 §11.1，产品口径见 `SESSIONS-SPEC.md` §5.3.1。
