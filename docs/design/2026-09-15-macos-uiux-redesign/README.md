# SpeechRail macOS App · UI/UX 重设计（macOS 26 原生）

> 版本：Proposal v1.0.0 · 2026-09-15
> 状态：`proposed` —— 本包描述**目标形态**，不代表当前实现，也不是对现有 active 设计系统的修改。

## 这个包是什么

一次针对 `macos/SpeechRailApp` 的界面与交互重设计，目标是让 App 同时符合两件事：

1. **产品定位**：SpeechRail 是运行在单台 Apple Silicon Mac 上的本地语音引擎，App 是它唯一的产品化入口 —— 让用户不必打开终端就能把引擎用起来，并在它不可用时知道原因。
2. **macOS 26 最佳实践**：材质、层级、圆角、工具栏、菜单与键盘路径交还给系统；品牌只负责强调色、字体节奏和一处关键动效。

## 落地顺序（建议）

1. **外壳先行**：去掉自绘工具栏底色与黑曜铺底，恢复系统材质、系统同心圆角与 scroll edge effect。这一步单独可见收益最大、风险最低，且不改任何业务逻辑。
2. **Token 收敛**：`SpeechRailDesignTokens` 的颜色/圆角/字体改为“系统语义优先 + 少量品牌色”，删除只被使用一次的自绘材质 token。
3. **命令与键盘**：补 `.commands` 菜单、页面快捷键与主操作快捷键。
4. **逐页重构**：配音台 → 音色创作 → 音色库 / 我的作品 → 服务四页。

每一步都应保持 App 可构建、可回退；运行态（服务启停、profile、模型）不在本包范围内。
