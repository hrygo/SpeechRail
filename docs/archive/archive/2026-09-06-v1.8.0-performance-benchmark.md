## 3. 说话人分离完整架构验收

本次发布吸收了 SPK-E2E-1 的完整架构优化，而不是只加入一个接口字段：

- R0：session-global 16 kHz integer sample timeline，统一跨 commit 的音频边界；
- R1：bounded continuous stream state 与 native capability probe；未通过真实探针时保持 `supports_stream=False`；
- R2：`speechrail.diarization.v1` 协商、completed attribution units、JSON Schema 与 fixtures；
- R3：bounded attribution ledger，多证据 speaker assignment、revision 单调性、`unknown` 降级和跨会话匿名 speaker links；
- R4：`finalize` draining barrier、pending update 排空、幂等重试、`last_update_sequence` 一致性与 degraded 状态；
- R5：离线 E2E 评测工具，覆盖 DER 的全局最优 speaker mapping、Collar/Overlap 和 SACER。

`1101` 个自动化测试包含上述契约、状态机、NeMo adapter、speaker centroid、异常/超限/回退路径。真实受管解释器上的 `probe_diarization_streaming.py` 找到 NeMo `3.0.0` 的 `forward_streaming` / `forward_streaming_step`，但 verdict 仍为 `candidate`，尚未完成真实 CPU smoke 与 RTF 注册门槛。实际 WS 验收结果为：capability 未广播，主动协商得到 `unsupported_operation`；这是设计的 fail-closed 结果，legacy Realtime 路径仍正常通过。

## 5. 切换与异常记录

执行顺序为 `quality → balanced → light → quality`。第一次 `balanced → light` 在 profile 内置 TTS→ASR smoke 阶段失败，CLI 自动恢复 `balanced`；未修改服务配置以绕过 gate。第二次切换到 `light` 通过，`light → quality` 通过。该事件保留为本版本的运行风险：CustomVoice 的一次空转写仍可能触发安全回退，但有限重试和回退路径有效。

## 6. 回退

保留上一 release、模型、vendor runtime、selection 和私有配置。回退使用 `speechrail profile rollback --app-home <app-home> --yes` 或按 wheel 发布 SOP 恢复上一 `runtime/current`，随后重新执行 `/health`、`/readyz`、模型/音色目录与真实 ASR/TTS smoke；不删除旧 release，不删除模型或 benchmark 原始制品。
