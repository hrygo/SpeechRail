## 修复与验证边界

v1.7.0 的 profile smoke 对 TTS→ASR 只尝试一次。CustomVoice 波形具有随机性，公共 TTS 与 ASR 均返回 HTTP 200 和 request ID 时，仍可能得到空转写并触发安全回滚。v1.7.1 只重试这一种空文本结果，每次重新生成 TTS，最多三次；缺 request ID、无效 WAV、超限、HTTP 或 JSON 错误仍立即失败。

回归测试覆盖：

- 第一次空文本、第二次成功：TTS 与 ASR 均调用两次，切换通过；
- 连续三次空文本：仍抛出 `SmokeProbeError`；
- 缺 request ID 或音频超限：只调用一次，立即失败。

安装后的真实切换三段全部首次通过。这个结果证明误回滚路径已改善，不证明 CustomVoice 每次都会生成相同 PCM。
