# SpeechRail v1.13.0 性能与质量基准

> 状态：有条件通过
> 范围：MINOR 三档（`quality → balanced → light → quality`）
> 测量：2026-09-08（Asia/Shanghai）
> 安装 commit：`4f29ccb`；版本：`v1.13.0`

## 一眼结论

| 结论 | 结果 | 证据 |
|---|---|---|
| 三档运行与恢复 | pass | 三次真实档位应用均通过公共 API smoke，最后恢复 `quality`；结束时单 listener、无 ESTABLISHED 连接 |
| 冷态启动与首请求 | pass | `quality` 两次重启到 `/health` 200 均约 13.8s；首个 10s ASR 为 0.618s，首个短 TTS 为 4.977s |
| ASR 基础性能 | pass | 三档四组同源 fixture（3.12/9.36/16.88/37.04s）warm N=5 均成功且转写非空 |
| TTS 基础性能 | pass | 三档 short/long、warm N=5 均返回非空 PCM；RTF 来自实测输出时长 |
| Realtime 当前 OpenAI profile | pass | 每档连续 3 session，ASR 终态非空 3/3，并只收到 `response.output_audio.delta` 当前事件族 |
| server-VAD 功能闭环 | pass | 每档均观察到 `speech_started`、`speech_stopped` 和转写终态 |
| 物理内存采样 | pass | 三档 batch+TTS 采样均 `gate_complete=True`，使用同 tick `phys_footprint` |
| ASR 准确率、VAD 误检/漏检、音质 | unset | 没有独立标注语料、人工 MOS/ABX 或 speaker embedding，不能以功能 smoke 代替质量证据 |
| 纵向可比性 | 部分可比 | ASR 与资源采样可对照 v1.11.0；TTS 文本集不同；Realtime 从 legacy 切到 current wire profile，只作并列观察 |

实测环境：Apple M5 Max、128 GB Unified Memory、macOS 26.6.2、Python 3.12.14。原始 JSON、资源采样日志、fixture 与私有运行器仅保存在仓库外 `$APP_HOME/benchmarks/20260908-v1.13.0-full/`；本报告不保留音频、转写、输入文本、API key、PID 或绝对路径。

## 方法与可比性

- 档位顺序为 `quality → balanced → light → quality`；每次切换前确认没有已建立的外部连接，应用命令完成候选 preflight 与公共 API smoke。
- ASR 使用与 v1.11.0 完全相同的四个外部 WAV fixture，SHA-256 前缀依次为 `5ab6f44c`、`4075ad`、`5cde37`、`03cb627`；时长为 3.12/9.36/16.88/37.04s。每组 warm N=5，表中为 p50，p95 采用 nearest-rank。
- TTS 以本轮固定的脱敏输入摘要运行 short/long 各 N=5，输出 `pcm`，输出时长由字节数按 24 kHz、PCM16、mono 换算。输入文本与 v1.11.0 不同，因此不计算纵向 delta。
- Realtime 使用相同的 10s、16 kHz、PCM16 fixture，嵌套 `audio.input`/`audio.output` current profile；每档连续新建 3 个会话。VAD 使用同一输入追加静音尾段，只验证事件闭环，不评价 FAR/FRR。
- 资源采样为每档 `batch+tts`、预热后 N=6；报告采用一次采样窗口中同 tick 进程 footprint 的最大和，不相加各进程历史峰值。

## 冷态与 ASR

### 冷态 `quality`

| 指标 | 结果 |
|---|---:|
| 服务启动至 `/health` 200（ASR 轮） | 13.818s |
| 首个 10s ASR 请求 | 0.618s |
| 服务启动至 `/health` 200（TTS 轮） | 13.786s |
| 首个 short TTS 请求 | 4.977s |
| short TTS 输出时长 | 3.920s |

冷态 ASR 与 TTS 分别通过受控 stop/start 测量；两轮之间会重启服务，故不把它们相加为单一“冷启动”数值。

### ASR warm p50（N=5）

| fixture 时长 | `quality` latency / RTF | `balanced` latency / RTF | `light` latency / RTF |
|---|---:|---:|---:|
| 3.12s | 0.140s / 0.0447 | 0.141s / 0.0452 | 0.093s / 0.0298 |
| 9.36s | 0.253s / 0.0270 | 0.260s / 0.0278 | 0.151s / 0.0161 |
| 16.88s | 0.458s / 0.0271 | 0.457s / 0.0270 | 0.253s / 0.0150 |
| 37.04s | 0.936s / 0.0253 | 0.930s / 0.0251 | 0.500s / 0.0135 |

所有 60 个 ASR 请求均返回成功、转写非空。`quality` 的 9.36s fixture p95 为 0.257s；`balanced` 为 0.265s；`light` 为 0.152s。

## TTS warm p50（N=5）

| profile | short latency / TTFA / output / RTF | long latency / TTFA / output / RTF | 同输入输出 SHA-256 数量 |
|---|---:|---:|---:|
| `quality` | 1.170s / 0.091s / 3.920s / 0.299 | 4.934s / 0.095s / 16.960s / 0.291 | 1 / 1 |
| `balanced` | 1.043s / 0.079s / 4.320s / 0.246 | 4.013s / 0.083s / 16.880s / 0.259 | 5 / 5 |
| `light` | 1.045s / 0.068s / 4.480s / 0.233 | 3.568s / 0.071s / 15.760s / 0.226 | 5 / 5 |

SHA-256 数量仅描述该固定输入、该次运行中返回字节流的可复现性；它不能证明音色相似度、自然度或跨版本稳定性。`quality` 本次相同输入为字节级一致，`balanced` 与 `light` 则每次返回不同字节流，均未纳入音质结论。

## 与 v1.11.0 的对照

v1.11.0 是最近一次同 fixture、三档 N=5 的可信性能基线。ASR 的历史值记录为 warm mean，本轮为 warm p50，因此下表仅用作方向性对照，而非硬性回归阈值。

| profile | 9.36s ASR：v1.11.0 → v1.13.0 | 37.04s ASR：v1.11.0 → v1.13.0 | 解读 |
|---|---:|---:|---|
| `quality` | 0.250s → 0.253s (+1.1%) | 0.880s → 0.936s (+6.3%) | 基本持平到轻微变慢；需重复采样再归因 |
| `balanced` | 0.250s → 0.260s (+4.2%) | 0.910s → 0.930s (+2.2%) | 轻微变慢；仍处于低 RTF 区间 |
| `light` | 0.180s → 0.151s (-16.3%) | 0.920s → 0.500s (-45.7%) | 变快；历史 60s 有 0.56–1.80s 大幅波动，不能据此宣称同等幅度提升 |

Realtime 的输入 fixture 相同，但 v1.11.0 记录的是 legacy `response.audio.delta`，本轮验证 current `response.output_audio.delta`；两者不能作为严格版本速度回归。TTS 的固定文本集不同，也只保留单版横向结果。

## Gate 与限制

| Gate | 状态 | 原因 |
|---|---|---|
| 公共 API、档位切换、冷态、ASR/TTS、Realtime、VAD 功能、资源采样 | pass | 有本轮直接实测 |
| ASR CER/WER | unset | 无独立标注的真人语料与评测器 |
| VAD FAR/FRR | unset | 无带 speech/silence 标签的独立测试集 |
| MOS/ABX、speaker embedding、跨重启音色稳定性 | unset | 无人工听测或独立声学评测材料 |
| 长时 soak / 并发上限 | unset | 本轮只覆盖连续 3 session 与 N=6 资源负载，不等同于长时并发压测 |

结束时服务为 `v1.13.0`、`quality`、ASR/TTS 均 active/ready，端口只有一个 listener，无已建立连接。回退方式仍为 managed runtime 保留的上一 release 加 `speechrail service`/profile controller；本次基准没有改动仓库内运行配置或模型文件。
