## 本轮发布内容

- 新增无状态 MCP 代理（`speechrail-mcp`）与 MCP server/client/tools，零配置 agent 访问。
- Realtime 增加 schema-aware Silero VAD v5/v6 与 `realtime_vad_engine=auto` 默认引擎。
- `speechrail setup` 在网络可达时自动下载固定 `silero_vad.onnx`（约 2.3 MB，MIT），并对 VAD 做 schema check。
- `service` 与 profile 命令补充 VAD 模型下载/管理。
- 修复 `auto` 解析为 silero 时被误判 shadow VAD 而拒绝的问题。
- `_atomic_write` 增加 `fsync directory` 提升元数据持久化。
