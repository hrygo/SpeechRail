## 方法与可比性

- 发布前后均检查 listener、`ESTABLISHED` 连接、`speechrail_realtime_active_sessions` 与 batch/realtime active requests；采样开始时全部为 0。
- 使用既有的仓库外 `quality` manifest，包含两个独立 ASR fixture（中文、英文）与一个中文 TTS fixture；每轮依次经公共 API 执行，warm N=5。
- 所有样本均在本轮已完成公共 smoke 后采集，cold 标记为 `cold_unavailable`，未与 warm 数据混用。
- 资源峰值为同一采样 tick 的 `phys_footprint` 求和。该 manifest 与 v1.13.0 三档报告的 fixture 集和套件不同，因此不计算版本 delta，也不设性能回归结论。

## Warm 结果（`quality`，N=5）

| fixture | status | latency p50 | RTF p50 |
|---|---:|---:|---:|
| 独立 ASR 中文短样本 | 5/5 | 0.254s | 0.0373 |
| 独立 ASR 英文短样本 | 5/5 | 0.241s | 0.0403 |
| TTS 中文短句 | 5/5 | 1.377s | 0.3073 |

五个结果文件的 `sampling_complete` 均为 true。同 tick `phys_footprint` 峰值中位数为 7373.1 MB，范围为 7284.1–7488.2 MB。采样完整性成立，但本轮没有预先冻结的性能或内存阈值，且没有同口径的 v1.13.0 基线，故该数据仅作观测记录。
