## 2. 进程与物理显存 (Footprint) 实测对比

> **测量口径**：采用 macOS 原生 `footprint` 采集真实物理显存/内存（`phys_footprint`）。预热后执行连续 4 轮全组件负载压测。

### 2.1 运行态组件内存对比表

| 进程组件 | 架构角色 / 运行命令 | v1.2.0 预热常驻 | **v1.3.0 预热常驻 (Footprint)** | **v1.3.0 压测峰值 (Peak)** | 优化与状态说明 |
|---|---|---|---|---|---|
| **主服务进程** | `speechrail serve` (PID 10827) | 559.8 MB | **527.8 MB** | **529.8 MB** | 路由、编排与音频解码缓冲 |
| **统一 ASR Worker** | `qwen3_worker.py` (PID 10962) | 6,475.7 MB | **4,629.0 MB** | **9,159.6 MB** | **合并 Batch 与 Streaming**，应用 256MB Metal 缓存限额 |
| **独立流式 ASR** | `qwen3_streaming_worker.py` | 8,446.2 MB | **0.0 MB (彻底移除)** | **0.0 MB** | **已彻底下线**，彻底根除 8.5 GB 重复常驻 |
| **Qwen3 TTS Worker** | `qwen3_tts_worker.py` (PID 10963) | 4,826.8 MB | **4,936.8 MB** | **5,309.8 MB** | VoiceDesign 1.7B bf16 合成，应用 256MB 缓存限额 |
| **总计常驻物理内存** | -- | **20,308.6 MB (~20.3 GB)** | **10,093.6 MB (~10.1 GB)** | **14,999.2 MB (~15.0 GB)** | **待机物理显存降 50.3%，峰值显存降 54.7%** |

### 2.2 显存治理效果分析
1. **消除重复载入**：v1.2.0 中 Batch 与 Realtime 分别拉起两个独立的 Python 子进程，各自加载完整的 1.7B 模型，造成了高达 8.5 GB 的显存白白浪费。v1.3.0 统一由 `qwen3_worker.py` 处理 `transcribe` 与 `session.open/append/commit`，彻底消除了冗余实例。
2. **显存池上限管理 (`--cache-limit-mb 256`)**：为 ASR 与 TTS Worker 注入了 MLX Metal 显存池上限管理，将峰值激增有效抑制，避免中间分配块在 128GB 大内存机器上无节制保留。
3. **显存即时释放 (`_clear_metal_cache`) 与 GC**：在每次推理和流式会话终止后主动调用 `mlx.core.metal.clear_cache()` 与 Python `gc.collect()`，有效抑制了 Metal 分配池在长周期运行下的无序膨胀。

* **结论**：ASR Worker 统一合并后，非流式推理延迟与准确率与优化前完全一致，无任何性能损失。

## 6. 生命周期与空闲回收治理 (Idle Eviction)

v1.3.0 引入了基于租约机制的 [`WorkerIdleEvictor`](file:///Users/hrygo/Documents/SpeechRail/src/speechrail/runtime/worker_lease.py)：

1. **工作机制**：
   * 每次 ASR / TTS 请求到达时，自动调用 `evictor.touch(worker)` 刷新租约活跃时间戳；
   * 后台巡检任务以 10s 为周期检查组件空闲时长；
   * 当连续空闲超过 `SPEECHRAIL_WORKER_IDLE_TIMEOUT_SECONDS`（默认 300 秒 / 5 分钟）时，异步触发 `worker.close()` 安全退出子进程，将占用的物理显存完整归还系统；
   * 新请求到达时自动触发惰性预热启动。
2. **极端待机收益**：
   * 在长时间仅作为系统后台服务待机时，TTS Worker（~4.9 GB）与 ASR Worker（~4.6 GB）被回收后，系统常驻物理内存将回落至 **~530 MB**（仅主服务进程）。

## 7. 验收结论

SpeechRail **v1.3.0** 经过真机全量性能与显存实测，各项优化指标全部超越预期：
* **显存削减**：待机常驻从 **20.3 GB 降至 10.1 GB (-50.3%)**，峰值从 **33.1 GB 降至 18.4 GB (-44.4%)**；
* **推理性能**：ASR 延迟 1.13s (RTF 0.11x)、TTS TTFA 46ms 保持 0 损失；
* **服务运行**：LaunchAgent `com.speechrail` 已在 macOS 环境平滑切换上线并稳定运行。
