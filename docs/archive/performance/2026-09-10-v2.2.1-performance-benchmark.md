## 纵向：与 v2.2.0 的方向性对照

`delta = v2.2.1 - v2.2.0`；延迟/RTF/内存下降表示更快或更省。百分比只在同口径下作方向性参考，不是冻结回归 gate。

| 指标 | v2.2.0 | v2.2.1 | Δ | Δ% | 判断 |
|---|---:|---:|---:|---:|---|
| ASR 3.12s warm p50 RTF ↓ | 0.0455 | 0.0463 | +0.0008 | +1.8% | 持平 |
| ASR 9.36s warm p50 RTF ↓ | 0.0257 | 0.0257 | 0.0000 | 0.0% | 持平 |
| ASR 16.88s warm p50 RTF ↓ | 0.0257 | 0.0257 | 0.0000 | 0.0% | 持平 |
| ASR 37.04s warm p50 RTF ↓ | 0.0242 | 0.0243 | +0.0001 | +0.4% | 持平 |
| TTS short warm p50 RTF ↓ | 0.2678 | 0.2695 | +0.0017 | +0.6% | 持平 |
| TTS long warm p50 RTF ↓ | 0.2639 | 0.2696 | +0.0057 | +2.2% | 持平 |
| HTTP 同 tick 峰值 ↓ | 6709.8 MB | 6673.8 MB | −36.0 | −0.5% | 持平 |
| Realtime ASR commit p50 ↓ | 396.0 ms | 380.9 ms | −15.1 ms | −3.8% | 持平/略快 |
| Realtime TTFA p50 ↓ | 35.1 ms | 35.5 ms | +0.4 ms | +1.1% | 持平 |
| Realtime 同 tick 峰值 ↓ | 6604.1 MB | 6524.7 MB | −79.4 | −1.2% | 持平 |

已确认的因果边界：

1. v2.2.1 相对 v2.2.0 的唯一产品改动是 `f996e21 fix(runtime): 解耦 worker 启动握手超时与帧 IO 超时以消除 CI 时序 flake`，仅触及 `src/speechrail/backends/qwen3_shared.py`（3 行）与 `src/speechrail/runtime/worker_process.py`（48 行）以及对应 fake worker/测试；未修改 ASR/TTS 权重、量化、推理图、采样或音色配方。
2. 该改动是启动握手超时口径的探测/CI 稳定性修复；生产环境 `handshake_timeout_seconds` 回退到请求超时，属行为中性。因此本轮 RTF/commit 的微小波动不能归因于推理变化。
3. 未设置预冻结噪声带，±2.2% 内的 RTF 差异与 −3.8% Realtime commit 均按“持平”处理，不写回归或改进结论。

### 资源

| 场景 | 进程集合 | 同 tick 峰值 phys_footprint | samples | complete |
|---|---|---:|---:|---|
| HTTP ASR+TTS | host + batch-asr + tts | 6673.8 MB | 99 | true |
| Realtime + TTS | host + batch-asr + tts | 6524.7 MB | 7 | true |

两个窗口 `sampling_complete=true`、`active_window_sampling_complete=true`，`internal_incomplete_ticks=0`、`boundary_incomplete_ticks=0`。本轮没有独立 idle 采样窗口，stable 常驻值记为 N/A；只发布完整 workload 窗口内的同 tick 峰值。Realtime session 较短，samples 少于 HTTP，但每个实际观测 tick 均完整。

## 限制与未验证

- 未执行独立 CER/WER、VAD FAR/FRR、MOS/ABX、speaker embedding、跨重启音色稳定性。
- 未执行 4 workers × 8 requests 吞吐、长时 soak 或并发上限专项；Realtime 仅覆盖显式 warm-up 后连续 3 session。
- `cold` 为 `cold_unavailable`：公共 smoke 已在采集前触发推理，不把预热后的首次请求当成严格冷启动。
- 本版 `/metrics` 未暴露 `speechrail_realtime_active_sessions`；隔离结论由 `lsof`、governor active/pending 与 streaming worker 状态共同支撑。
- 纵向数字只用于方向性对照；本版范围未改推理权重/量化/推理图，只改动启动握手超时口径，不把单轮差异写成回归或改进结论。
- 三档横向对比本轮不适用（PATCH 只测当前 `quality`）。
- 未把任何报告值同步到 README；性能索引会更新，README 按项目约定保持不变。

## 复现

原始制品在仓库外（`<app-home>/benchmarks/20260910-v2.2.1/`），命令中的 `$APP_HOME` 仅表示本机 managed app home：

```bash
APP_HOME="${SPEECHRAIL_APP_HOME:-$HOME/Library/Application Support/SpeechRail}"
uv run python examples/perf/bench_profiles.py \
  --base-url http://127.0.0.1:8201 \
  --app-home "$APP_HOME" \
  --manifest <external-manifest.json> \
  --profile quality \
  --phase warm \
  --output <external-quality.json>
uv run python examples/perf/bench_realtime_json.py <external-16khz-pcm> \
  --profile quality --output <external-quality-realtime.json> \
  --app-home "$APP_HOME"
```

PATCH 不切换档位；采集前后检查外部连接、governor active/pending 与 profile identity，结束后复查 `/health`、`/readyz`、`/v1/models`、`/v1/voices`、公共 smoke 与 `/metrics`。分位数按 nearest-rank 计算；RTF 使用 ffprobe（ASR）与返回 PCM 字节（TTS）实测时长。
