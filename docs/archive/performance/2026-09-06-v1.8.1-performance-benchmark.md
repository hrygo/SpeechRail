## 限制与未验证

- 本 patch 只覆盖当前 `quality`；`balanced`、`light`、Realtime 和 idle standby 未重测。
- v1.8.0 报告没有保存 fixture digest，因此纵向性能比较标为部分可比；性能噪声带也尚未冻结。
- 真实质量、人工听感、speaker embedding 和 ABX 未在本轮执行，不能据此声明识别准确率或音色身份稳定。
- 开发环境中存在 ambient `SPEECHRAIL_API_KEY`；全量 pytest 使用仅移除该环境变量的临时进程环境重跑通过，私有 managed 配置未修改，凭据未输出。

## 复现

原始 JSON、音频和日志保存在仓库外的 benchmark 目录；可用同一外部 fixture manifest 重复以下命令：

```bash
uv run python examples/perf/bench_profiles.py \
  --base-url http://127.0.0.1:8201 \
  --manifest <repo-external-manifest.json> \
  --profile quality \
  --phase warm \
  --output <repo-external-result.json>

uv run python examples/perf/sample_resources.py \
  --host http://127.0.0.1:8201 \
  --audio <repo-external-audio.wav> \
  --mode all \
  --n 5 \
  --warmup
```

API key 只从环境读取；命令、报告和日志不包含凭据、完整 prompt、完整转写或绝对模型路径。
