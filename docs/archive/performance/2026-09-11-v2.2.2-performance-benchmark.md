## 纵向：与 v2.2.1 的方向性对照

`delta = v2.2.2 - v2.2.1`；延迟/RTF/内存下降表示更快或更省。百分比只在同口径下作方向性参考，不是冻结回归 gate。

| 指标 | v2.2.1 | v2.2.2 | Δ | Δ% | 判断 |
|---|---:|---:|---:|---:|---|
| ASR 3.12s warm p50 RTF ↓ | 0.0463 | 0.0446 | −0.0017 | −3.7% | 持平 |
| ASR 9.36s warm p50 RTF ↓ | 0.0257 | 0.0252 | −0.0005 | −2.2% | 持平 |
| ASR 16.88s warm p50 RTF ↓ | 0.0257 | 0.0253 | −0.0004 | −1.6% | 持平 |
| ASR 37.04s warm p50 RTF ↓ | 0.0243 | 0.0241 | −0.0002 | −0.8% | 持平 |
| TTS short warm p50 RTF ↓ | 0.2695 | 0.2713 | +0.0018 | +0.7% | 持平 |
| TTS long warm p50 RTF ↓ | 0.2696 | 0.2669 | −0.0027 | −1.0% | 持平 |
| HTTP 同 tick 峰值 ↓ | 6673.8 MB | 6921.8 MB | +248.0 | +3.7% | 持平/噪声 |

已确认的因果边界：

1. v2.2.2 相对 v2.2.1 的唯一产品改动是把 `speechrail-mcp` 代理迁移到 MCP Python SDK v2（`src/speechrail/mcp/server.py`、`tools.py`）并把 `mcp` 依赖收紧为 `>=2,<3`；未修改 ASR/TTS 权重、量化、推理图、采样或音色配方，也未触碰 `backends/`、`runtime/`。
2. 该改动只影响独立的外置 MCP 代理进程；代理不导入 FastAPI 应用，也不实例化任何模型 worker，因此不参与批量/流式推理延迟。
3. 未设置预冻结噪声带；±3.7% 内的 RTF/峰值差异按“持平”处理，不写回归或改进结论。

## 限制与未验证

- 未执行独立 CER/WER、VAD FAR/FRR、MOS/ABX、speaker embedding、跨重启音色稳定性。
- 未执行 Realtime、4 workers × 8 requests 吞吐、长时 soak 或并发上限专项。
- `cold` 为 `cold_unavailable`：公共 smoke 已在采集前触发推理，不把预热后的首次请求当成严格冷启动。
- 复用的外部 manifest 内嵌 `software.speechrail=2.2.1` 标签，与运行态 `2.2.2` 不一致（见「测量身份与可比性」）；fixture 路径与字节一致，性能口径可比。
- 纵向数字只用于方向性对照；本版范围未改推理权重/量化/推理图，不把单轮差异写成回归或改进结论。
- 三档横向对比本轮不适用（PATCH 只测当前 `quality`）。
- 未把任何报告值同步到 README；性能索引会更新，README 按项目约定保持不变。

## 复现

原始制品在仓库外（`<app-home>/benchmarks/20260911-v2.2.2/`），命令中的 `$APP_HOME` 仅表示本机 managed app home：

```bash
APP_HOME="${SPEECHRAIL_APP_HOME:-$HOME/Library/Application Support/SpeechRail}"
uv run python examples/perf/bench_profiles.py \
  --base-url http://127.0.0.1:8201 \
  --app-home "$APP_HOME" \
  --manifest <external-manifest.json> \
  --profile quality \
  --phase warm \
  --output <external-quality.json>
```

PATCH 不切换档位；采集前后检查外部连接、governor active/pending 与 profile identity，结束后复查 `/health`、`/readyz`、`/v1/models`、`/v1/voices`、公共 smoke 与 `/metrics`。分位数按 nearest-rank 计算；RTF 使用 ffprobe（ASR）与返回 PCM 字节（TTS）实测时长。
