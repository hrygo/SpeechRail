## 本轮发布内容

- Realtime ASR 增加 speech admission 与 neural VAD，静音或非语音输入不会直接进入转写提交路径。
- 增加 controller-backed `service start`、`stop`、`restart`，并把 per-port singleton lock、精确旧进程恢复、严格 profile smoke 和安装切换检查接入发布路径。
- cartoon-avatar 示例补充 avatar profile、voice binding 和 playback progress 交互。
