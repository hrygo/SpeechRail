| balanced | 30s | 0.4763s | 0.44s | -0.036 | -7.6% | 未归因 |

## 限制与未验证

- **TTS 纵向不可比**：文本集与 v1.10.0 不同，RTF 虽按实测时长归一，但声学内容与韵律不同，不计算纵向 delta。
- **light 60s 单点异常**：min 0.56 / max 1.80s，mean 0.92s，已单列，未并入回归判断。
- **无质量证据**：独立真人 CER/WER、MOS/ABX、speaker-embedding 均未纳入本轮（与 v1.10.0 保持一致，质量门 `unset`）。
- **ASR/Realtime 变快未归因**：跨会话运行噪声；本轮为纯行为/基础设施改动，未触碰推理模型。
- v1.11.0 变更内容：`/health` 就绪语义（新增 `asr_state`/`tts_state`/`streaming_state`）、系统路由鉴权、语音克隆原子持久化、流式计时中间件、`voice_class` 指标降基数。

## 复现

```bash
# 逐档切换后运行
uv run --extra dev python examples/perf/bench_asr.py \
  --audio <3s/10s/30s/60s.wav> --base http://127.0.0.1:8201/v1/audio/transcriptions --n 5
uv run --extra dev python examples/perf/bench_tts.py --text <text> --voice serena \
  --base http://127.0.0.1:8201/v1/audio/speech --repeat 5
uv run --with openai python examples/perf/bench_realtime.py <audio_10s_16k.pcm> \
  --base-url http://127.0.0.1:8201/v1 --sessions 3
uv run --extra dev python examples/perf/sample_resources.py --mode batch|tts --n 6 --warmup
```

API key 只从 `SPEECHRAIL_API_KEY` 读取，不落盘。
