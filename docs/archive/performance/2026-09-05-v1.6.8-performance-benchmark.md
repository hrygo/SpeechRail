# SpeechRail v1.6.8 性能基准与资源监控报告 (Performance Baseline Report)

> **测试版本**：`SpeechRail v1.6.8`（发布后 LaunchAgent wheel runtime）
> **报告时间**：2026-09-05
> **测试环境**：Apple M5 Max（18 核 CPU / 128GB unified memory），macOS 26.6.2，arm64，Python 3.12，MLX (MPS)
> **测量工具**：macOS 原生 `footprint -f bytes`、`examples/perf/bench_asr.py`、`bench_tts.py`、`bench_realtime.py`、`sample_resources.py`（由 `run_all_benchmarks.py` 串行执行）
> **运行状态**：`/health` 返回 `version=1.6.8`，ASR/TTS/diarization 全部 ready；`/readyz`、`/v1/models`、`/v1/voices` 均 HTTP 200。
> **安全边界**：基准通过私有运行配置提供 API key；本报告不记录 key、`.env` 内容、绝对模型路径或完整转写正文。

本轮结果证明新版本可在真实本机模型与已安装服务 runtime 上完成完整基准流水线。内存数据采用 `footprint` 的物理 footprint，而不是 `ps` RSS；音频 RTF 采用 `ffprobe` 的实际时长，而不是 3/10/30/60 秒名义标签。

## 1. 真实物理内存与 CPU 资源基线

> `sample_resources.py --audio /tmp/audio_30s.wav --mode all --n 5 --warmup`。Peak(Total) 是逐采样 tick 的当前 footprint 之和的最大值，不是逐进程生命周期峰值的简单相加。

| 进程组件 | 冷启待机 | 预热常驻 (Idle) | 压测峰值 (Peak) | 峰值 CPU |
|---|---:|---:|---:|---:|
| 主服务 FastAPI | 537.3 MB | **538.5 MB** | **538.7 MB** | 0.9% |
| ASR Worker (batch) | 2501.8 MB | **2502.7 MB** | **4060.6 MB** | 92.4% |
| ASR Worker (streaming) | 2560.1 MB | **2556.3 MB** | **3424.8 MB** | 0.0% |
| Qwen3 TTS Worker | 3557.4 MB | **3557.3 MB** | **3979.1 MB** | 1.6% |
| **四进程总物理常驻** | -- | **9154.9 MB (~9.15 GB)** | **10355.3 MB (~10.36 GB)** | -- |

相对 v1.6.7 报告的预热总常驻 `9166.5 MB`，本轮 `9154.9 MB` 基本持平；峰值从 `9731.6 MB` 到 `10355.3 MB`，差异来自单次压测窗口，当前证据不足以归因于代码回归。

## 5. Realtime 流式基线（连续 3 会话）

使用安装有 `openai` SDK 的本地 Python 环境，输入 `/tmp/audio_10s_16k.pcm`，模型 alias 为 `whisper-1`。

| 会话 | 握手 setup | ASR commit | RTF | TTS 首包 (TTFA) | TTS 字节 | 结果 |
|---|---:|---:|---:|---:|---:|---|
| session 1 | 67 ms | 1104 ms | 0.13x | 49 ms | 138240 | ✅ 完成 |
| session 2 | 0 ms | 457 ms | 0.06x | 44 ms | 163840 | ✅ 完成 |
| session 3 | 0 ms | 592 ms | 0.07x | 78 ms | 143360 | ✅ 完成 |

3 个会话均完成；session 1 为首个实时请求冷路径，稳定会话的 ASR commit 为 `457–592 ms`，TTFA 为 `44–78 ms`。

## 6. 复现步骤

```bash

set -a
source "$HOME/Library/Application Support/SpeechRail/config/.env"
set +a

uv run python .agents/skills/speechrail-perf-benchmark/scripts/run_all_benchmarks.py \
  --host http://127.0.0.1:8201
```

- 本轮是 v1.6.8 发布后的单次完整基准，不是长时间 soak、泄漏测试或多轮统计置信区间。
