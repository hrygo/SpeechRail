数据来自新模块化 benchmark runner 的真实公共 API 调用；每档使用两条 ASR fixture 和一条 TTS fixture，N=1，不与已有 N=5 报告直接比较。

## 本轮固化的改进

1. `LaunchAgentServiceController` 的生命周期实现集中到 `speechrail.service.lifecycle`；`profile_switch` 只保留 profile 事务，避免安装、切档和普通重启各自复制 stop/kill 逻辑。
2. `port=None` 的测试/无端口路径直接返回，不再在 bootout 后强制 sleep；有端口路径仍以同一 singleton lock 作为事实，不把 `launchctl` 返回码当作进程已退出。
3. managed installer 不再负责复制用户 skill；skill 安装独立为 `speechrail.service.skill_installer`，错误和原子替换边界可单独验证。
4. 基准入口拆为 manifest、HTTP、resource monitor 和 runner；旧的自动生成 TTS fixture、写死 `/tmp`、吞掉 realtime 失败的 all-in-one wrapper 已删除。
5. 新 benchmark 默认启用真实资源 monitor；采样器动态发现懒加载 worker，同时记录 RSS、`phys_footprint` 和 start-time identity，缺样会关闭 gate。
6. 发布、安装、停启、切档和基准 skill 共享同一份 operator contract；文档检查脚本和 skill quick validation 已通过。

## 未验证与后续

- 本轮没有重做三档完整 N=5、Realtime 三 session、独立真人 CER/WER、MOS/ABX 或 speaker embedding；这些结果仍以既有正式 v1.10.0 报告为准。
- 本轮报告不宣称新的跨版本性能回归结论；要更新发布承诺，必须按 `speechrail-perf-benchmark` 完整套件重新测量并同步 README。
- wheel 安装后的 managed runtime、单 listener、ready 和公共 smoke 已复核；回退目标仍保留在旧 release/current 记录中。
