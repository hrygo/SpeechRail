# 有声书音色跨作品复用修复计划

> 执行方式：当前会话实施，独立测试与最终审查；不自动提交、安装或操作前台窗口。

**目标：** 已登记的活跃剧组音色可用于任意小说和文稿版本；来源不构成独占授权，书内角色独占仍有效。当前《彷徨》使用已有音色重新匹配，不重复生成。

**架构：** 保留既有来源字段和持久化枚举，统一候选与界面可见性规则。重新配声通过 Store 生成完整方案并原子应用，保留撤销记录与既有音频。

## 任务与验收

- [x] 在 `AudiobookCastTests.swift` 补跨书候选、特征匹配、归档/未知拒绝回归，观察修复前失败。
- [x] 在 `AudiobookDomain.swift` 统一跨书复用语义；`CreatorSurfaceViews.swift` 显示“剧组来源”与跨作品可用说明。
- [x] 在 `AudiobookCastRegistry.swift` 区分目录、归档、验收与容量问题；在 `AudiobookWorkflowModel.swift` 避免将可复用音色误判为需创建。
- [x] 提供按特征重新配声方案，覆盖已有绑定而不改其他书籍；保留显式确认、事务校验与撤销。
- [x] 同步当前规格和用户文档；运行针对性 fake 回归与必要编译验证。
- [x] 备份当前作品，读取实时能力，使用生产规划与原子应用路径对当前《彷徨》重新分配；核对未绑定发声角色、音色分布、其他作品不变。

## 审查重点

来源书籍已删除、同名不同版本、归档/未知元数据、引擎验收过期、已有人工选择的显式重配。任何声音复用不改变源作品的绑定，也不绕过正式制作准入。

## 回退

代码可撤销本分支差异。当前作品通过 casting revision 撤销恢复上一组绑定；仓库外备份保留原数据库与目录。不得覆盖修复后新增作品。

验证结果与回退边界见 [修复验证记录](../../audits/2026-10-21-audiobook-voice-reuse-review.md)。
