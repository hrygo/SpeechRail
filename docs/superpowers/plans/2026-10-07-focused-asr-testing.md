# #336 定向 ASR 诊断与修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 本次按用户持续授权由主代理直接实施；保留已有八项验收范围。

**Goal:** 用最小的、可区分假设的实验定位 SpeechRail 引入的额外错误，再修复具体机制，避免无新假设地重复完整矩阵。

**Architecture:** 复用既有公共 Realtime 客户端、真实单 worker 和仓库外素材。离线分析器只比较脱敏分段结果；定向执行器按明确的 fixture ID 选择样本。定位、单因素归因、生产修复和最终验收分别记录证据。

**Tech Stack:** Python 3.14、pytest、现有 OpenAI SDK Realtime 客户端、managed runtime。

**Spec:** 本计划下方的诊断设计；完整验收范围仍以 #336、#253 和 `docs/implementation/2026-10-07-issue-336-asr-acceptance.md` 为准。

## Global Constraints

- 不扩大冻结的提词器 500ms / 8s / `streaming_finalize`；不恢复已拒绝的 20s 方案。
- 同一服务、同一 worker；不下载模型、不并发加载模型、不接管 UI、不采集真实麦克风。
- 音频、参考、转写、原始结果、配置和维护制品均保存在仓库外。
- 参考答案只用于离线评分，不进入模型 context，不参与生产输出选择。
- 不按 fixture ID、摘要、语言专名或错误位置编写生产修复规则。
- 任何维护均保留原 runtime/vendor、配置/selection/plist 的字节与权限，结束或失败后恢复并独立核验。
- 分段文字对齐不是声学定位；字符位置不是音频时间戳。
- 初始筛选通过不是完整验收通过；保留所有退化记录及未设阈值。

## Review Focus

- 配对使用不同 reference、策略、顺序或音频时长：拒绝比较；音频字节、模型/精度、worker 和制品身份另由冻结 proof 核验。
- 相同 CER 但文字、标点、空白或最后预览变了：必须独立保留，不以总分或终态相同隐藏变化。
- 标点 F1 配对必须核验同一份标点 gold 精确摘要；仅 CER 规范化参考相同不足以证明 gold 相同。
- 历史结果没有 exact 摘要时标记 `not_observed`，不回填、不声称原输出全文相同。
- 分段边界变化或预览缺失：不得推断错误只来自最终解码。
- 重复结果不一致：展示每次结果与不一致状态，不多数投票抹掉退化。
- fake、部分结果、缺覆盖、重复请求或目标不存在：失败退出，不输出成功计划，不启动额外请求。

## 诊断设计

### 1. 先利用已有证据

2026-10-07 22:49 UTC（Asia/Shanghai 为 10 月 8 日 06:49）完成的两组 core 分段诊断各含 24 次正式请求、1 次 warmup。冻结 main 为 `3a4cb71357095cdb5a92d05630e86a07d4c9a27d`，candidate 为 `2aeb670cff791049fc28f592c59b258b3d4dc73f`；结束后原服务恢复，22:52 UTC 的独立核验确认单 listener、generation 13、quality/quality、auto off、零活动请求以及原文件字节和权限。

`fleurs-zh-04` 三次重复均为 main 1 个字符错误、candidate 2 个。第一段为 wire `[0, 192000)`，即固定 8 秒；两组最后预览的规范化摘要相同，candidate final 新增 reference `[4, 5)` 的替换错误。第二段摘要相同。这里没有声学词边界，不能称为“第几秒的错误”。

对比 `librispeech-5639-40744-0030`：candidate 从 2 个错误改善至 0，第一段也出现相同最后预览、不同 final。它是必要的收益保护样本：不能用无条件保留预览来修复一个退化，同时消除已经测得的纠错收益。

`ami-meeting-06` 从 27 改善到 22，两组最后预览已不同。它用于区分初始可修订窗口与最终解码的影响。另选一个两组均零错误的样本保护不变行为。

### 2. 问题分层与停止条件

| 层 | 要回答的问题 | 最小证据 | 继续条件 |
|---|---|---|---|
| 消费/协议 | 是否丢 PCM、错 item、重复或缺终态？ | fake 状态机测试及原有 receipt/span 断言 | 工程断言失败才扩大该层测试 |
| 切分 | 错误是否随固定边界变化？ | 同音频、相同模型、一次只改边界因素 | 已有分段差异且可检验假设 |
| 预览 | 更长可修订窗口改变了哪些输出？ | 最后预览摘要及初始窗口单因素消融 | 预览路径存在变化 |
| 收尾 | final 是否改变相同预览并新增错误？ | 相同边界和预览，不同终态；再隔离 final 策略 | 收尾路径存在变化 |
| 模型 | 不加历史强制前缀时，原始模型是否仍出同一错误？ | 相同精确段 PCM、语言/context、预算与精度的独立完整段解码 | 该比较能区分工程损失与模型输出 |
| 产品 | 关键语义、标点可读性和设备体验是否可接受？ | 分项指标及必要人工验收 | 不用 CER 或客户端末尾计时代替 |

同一配置的稳定结果已经重复三次后，禁止无新变量地继续重复。遇到模型输出取舍时记录能力与策略边界，不凭 gold 选生产结果，不把重复测试当作修复。

### 3. 定向池与单因素消融

首轮每个观察家族选一个代表，保留全部原始比较：

- 收尾退化：`fleurs-zh-04`。
- 收尾收益：`librispeech-5639-40744-0030`。
- 预览路径收益：`ami-meeting-06`。
- 不变且零错误的对照：按 manifest 原顺序选择第一个。

两项变更分别记为 A（初始窗口：两次预览 / 4 秒 PCM）和 B（final：回退前缀 / 无前缀）。四组组成 2×2 消融：原 main、仅 A、仅 B、A+B。只制作隔离实验制品，不给生产配置增加临时开关。其他源文件、模型/精度、PCM、语言/context、token budget、预览间隔和 8 秒预算全部冻结。

首轮每组每素材 N=1，共最多 16 个正式请求。只有观察到能区分假设的变化后，才对决定修复的退化/收益对做 N=3 确认。缩小池改变了执行顺序与 warmup，需要记录，不能把旧 35 矩阵证据自动当作本实验的控制组。

先保持原素材，避免裁剪改变声学上下文。需要缩小时按已观测的 wire 边界生成派生素材，保留原摘要、采样范围及重采样来源；没有词级时间 gold 时不为裁剪片段伪造局部参考。

### 4. 修复与扩大验证

只有单因素实验支持机制后，才修改对应生产代码并补 fake red/green 测试。例如：若 B 单独引入退化，只处理最终解码；若 A 单独影响结果，只处理预览窗口。不得同时调 preview、rollback、segment length 或语言提示。

修复候选须同时检查失败样本、收益样本及不变对照。发现任何新退化，保留该候选和证据，不采用。初筛有效后：

1. 三个独立的已知退化素材及标点类别补充池；
2. 未用于调参的素材与输入变体；
3. 相关四生产消费者的确定性断言；
4. 只有实际待验制品确定后，才进行一次必要的完整配对验收。

不以平均改善覆盖逐项退化。若合理输入下无前缀完整段模型仍错，记录为模型/策略能力边界；仍检查 SpeechRail 是否另有可修复损失，不承诺零错误。
