# 增量 TTS 生产与播放解耦

用户授权：彻底修复同一语音助手故障，遵循 SOLID；已有替换安装授权持续有效。

## 已确认缺陷

- worker 的 pending PCM 预算尚未被 writer 归还时，host 立即以 `tts_backpressure` 结束。
- 消费窗口等待处在发送 sink 的固定超时内，健康播放的累计等待被误判为传输阻塞。
- 消费窗口与单帧/worker 预算使用相同上限，客户端无法充分预取。

## 实施边界

1. 先建立失败回归：预算满暂停、真实 Pump 延迟写入后继续、等待期间取消与 EOF、无进展超时。
2. host 仅在模型线程更新状态机；writer 通过同步信用回执通知，Pump 用活动代数唤醒等待，避免忙轮询和丢唤醒。
3. 消费准入独立于网络发送，消费超时按实际水位进展续期，重复 ACK 不续期。保持终态唯一与取消释放屏障。
4. 客户端总预取窗口独立于播放器和单帧预算，最大 30 秒 PCM（1,440,000 bytes）；单帧/worker 仍有界。同步当前契约、DTO、文档与测试。
5. 定向 Python/Swift 测试、契约检查与独立审查；构建和安装受影响制品，备份现装版本，验证 managed runtime 与 App 唯一登记。

## 验收与回退

- fake model + 真实 Host/Pump/驱动通过生产 IPC，不访问模型/音频设备、不做 UI 自动化。
- 正常消费超过单次网络超时仍完成；停止消费有界失败；文字与取消可在音频等待时处理。
- 验证连续 sample offset、精确字节预算、终态唯一、资源释放和跨 request 隔离。
- 不修改用户数据、私有配置、模型或音色。安装前保存当前服务 wheel/App 备份与身份快照，失败恢复原安装。
- 真实播放与音质未经本轮确定性测试证明，交付时明确区分。

## 2026-10-05 验收结果

- 178 项定向 Python 测试通过，最后的消费 deadline 调整另以 25 项测试复核；139 项定向 Swift 测试通过，Ruff、7 文件 Mypy、版本一致性和 diff whitespace 检查通过。
- fake model 经真实 Host/Pump/IPC/父进程 client/控制器/消费窗口完成 80 段连续 PCM，覆盖健康消费跨越单次 deadline、样本偏移、字节预算与单终态。
- 实际 writer 延迟恢复、控制文字/取消/EOF、drain 与活动快照间的竞态均有回归；独立审查发现的 guard 不一致与丢唤醒已修复。
- managed 服务候选摘要 `b96018d008fa` 已安装；App 3.7.1/build 47 已安装。服务 ready、唯一 listener、安装源码摘要、原配置与模型/音色身份、App 签名/XPC/唯一登记通过；保留前一服务 release/wheel 和 build 46 ZIP。
- App 未启动，未执行 UI 自动化、真实音频播放、模型推理或性能/音质基准。完整证据与回退记录留在仓库外 deployment 目录。

## 2026-10-05 CI 与尾音修正

- rebase 到 `origin/main`，保留远端合并结果的回退点；核对重放后的文件树与远端合并结果相同。
- Swift 的消费进度续期测试原本依赖 40 毫秒真实计时，在 CI 调度负载下失败。单独注入 deadline sleeper，测试主动触发已取消的旧定时器，并验证无进展仍然超时；生产默认计时不变。
- 两个基准调用方补齐必填 `audio_window_bytes`，计数并丢弃 PCM 后发送累计 `audio_ack`；这次只运行 fake backend 的契约测试，不运行性能或质量基准。
- worker 测试保持父输入连接到模型结束，避免把 EOF 取消当作成功合成；同步 rebase 带入的新提词器实现对应的 mutation 锚点。
- 尾音从“复制末个采样值并附加直流斜坡”改为保留原 PCM 最后 5 毫秒，由独立 `Pcm16Tail` 处理波形淡出。额外保留最多 240 bytes；样本数量不变，终点归零，预算不足时分块等待并发送尾部，再发送 completed。取消或失败丢弃保留尾部。
- 16 组短音频/极小预算用例先在旧实现失败，再在新实现通过；覆盖波形符号、幅度递减、样本总数、offset 连续、预算与终态顺序。同步真实 pipe 和父进程 client 的集成断言。
- 最终 Python 全套 3,222 项通过、1 项跳过，覆盖率 82.86%（超过 80% 门槛）；Swift 全套 695 项 XCTest 与 419 项 Swift Testing 通过。全量 Ruff、160 文件 Mypy、版本一致性及 diff 检查通过。这些是确定性验证，不能替代真实听感验收。
