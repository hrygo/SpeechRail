# 展示格式统一实施计划

**Goal:** 界面与人类可读导出共用展示方法，按场景选择单位，保留缺失值、任务完成状态及技术格式的语义。

**Architecture:** 纯 Foundation 的 `SpeechRailDisplayFormat` 负责时间码、中文时长、倍速、进度、容量与缺失值；日期方法移到同一文件。业务状态与协议值不改变，音色技术属性采用渐进披露。

**Tech Stack:** Swift 6、Foundation、Swift Testing、现有 SwiftPM / Xcode target。

**Spec:** 当前会话确认的六类展示统一要求及 `docs/developers/macos-app-design-system.md`。

## 约束与验证重点

- 保留已有未提交改动；只修改展示、相关测试和规范；不安装、不改运行态、不执行 UI 自动化。
- 时间码向下取整，不提前跳秒；跨小时显示 `h:mm:ss`，中文时长按音频、经过时间、历史跨度选择精度。
- 倍速使用 `×`，最多两位小数且去除末尾零；非有限输入不得崩溃或伪装成零。
- 进度保留真实完成状态，进行中最多 `99%`；小文件不显示为 `0.0 GiB`。
- 磁盘/下载用十进制容量，内存用二进制容量；缺失、零、未读取、无样本分别表达。
- 保留字幕、协议、持久化和文件名格式；音色未知模式不伪装为已知模式。
