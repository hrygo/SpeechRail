# 语音助手人工验收清单（U）

- 范围：只覆盖须人眼/人手确认的 U 项；D 结果不得代替本清单。任一项未执行即记 `not_run`。
- 前置授权：前台 UI 操作须当前用户逐次明确要求，并先说明占用窗口与预计时长；本文件不构成执行授权。

- 基线记录：macOS 版本、App commit、窗口尺寸 tier、输入法、显示模式（Light/Dark/高对比）、VoiceOver/Reduce Motion 开关。

## U31 IME 与键盘路由（A31 / VA-09）

| 步骤 | 预期 |
|---|---|
| 中文拼音组合中按 Return | 留在候选确认，不发送 |
| 候选展开时按 Return / Esc | 确认候选或关闭候选，不发送、不穿透到底层按钮 |
| 纯换行 Return | 换行不发送 |
| ⌘Return | 发送当前草稿 |
| 发送等待期间继续键入 | 新文字保留，只清发送快照（对应 D 的 A29） |
| 焦点在弹窗/菜单时按 Esc | 先关弹窗/菜单，不触发结束或停止 |

状态：`not_run`。证据：操作者、时间、基线、逐项 pass/fail。
