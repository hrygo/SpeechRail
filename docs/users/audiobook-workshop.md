# 有声书工坊使用指南

「有声书工坊」（快捷键 `⌘5`）让你把一整本中文或双语 `.txt` 小说、非虚构作品或长文稿导入 SpeechRail，在本机完成章节整理、角色识别、多角色配音、逐段返修、沉浸收听与标准 `.m4b` / 分章 `.mp3` 导出。

## 1. 五步完成一本有声书

### 第一步：导入 TXT 书稿
1. 在左侧边栏「创作」分组点击 **有声书工坊**（或按 `⌘5`），点击右上角 **导入 TXT**。
2. 选择本机 `.txt` 文件（支持 UTF-8、UTF-16、GB18030 等常见中文编码，单本上限 64 MiB）。
3. 导入完成后，SpeechRail 会在本机建立只读规范化原文副本，并自动扫描「第X章 / 第X回 / Chapter X / 序章 / 尾声」生成章节目录。

### 第二步：确认目录与分章
1. 在工作台阶段 1 **目录与分章** 中查看自动识别的章节列表、字数与预计朗读时长。
2. 如遇无标题长文或分章过细，可在章节上选择 **向上合并**、**在段落处拆分** 或 **重命名章节**。所有调整只更新章节边界，不修改原文字句。

### 第三步：全书角色梳理与音色试听
1. 切换到阶段 2 **角色与音色**，点击 **开始全书角色分析**。系统会基于你在「设置 ▸ 助手」中配置的对话服务（或「有声书理解」专用配置）通读各章，提取出场角色、性别/年龄/声线特征，并把每段对白归属到对应角色。
2. 若某句台词上下文模糊，系统会将其标为 **待确认** 并默认使用旁白音色朗读，不会擅自猜测说话人；你可以在右侧详情面板一键指派给具体角色或保持旁白。
3. 为 **旁白** 和 **主要角色** 选择系统音色或你的克隆/设计音色，点击 **生成试听样本** 听一段真实合成效果，满意后勾选 **已试听确认**。

### 第四步：章节合成與逐段返修
1. 通过旁白与主要角色的试听门禁后，进入阶段 3 **章节制作**，点击 **生成当前章节** 或 **生成全书**。
2. 合成按切片流式落盘：你可以随时暂停、关闭应用或重启电脑，下次打开会从最后完成的切片继续，已生成的音频不会丢失。
3. 如果某一段读音或语气不满意，点击该段右侧的 **重录 / 返修** 打开段落返修面板：
   - 可以临时微调语速、更换音色或改派说话人后重新生成候选音频；
   - 在面板中对比 **当前采用版本** 与 **新候选版本**；
   - 只有点击 **采用此候选** 才会替换正式成书中的这一段，并且随时可以点击 **撤销上次采用** 恢复原版，其余段落与章节完全不受影响。

### 第五步：沉浸收听与导出成书
1. 点击右上角 **收听模式**，即可像听书软件一样按章连续收听：正文随声音高亮滚动，自动记住收听位置与倍速；听书过程中发现某段不自然，可直接点段旁的 **重录本段** 原位返修。
2. 在阶段 4 **导出成书** 中选择：
   - **单文件有声书 (`.m4b`)**：内嵌章节书签与封面元数据，可直接导入 Apple 图书 (Books) 或播客客户端；
   - **分章音频包 (`.mp3`)**：按 `001-第一章.mp3` 顺序输出独立章节文件与 `manifest.json` 校验清单。

## 2. 常见问题与排障

- **提示「未配置可用的大模型服务」**：打开 `⌘,`（设置 ▸ 助手），填写全局对话服务或展开「高级：按功能单独设置」配置「有声书理解」连接，点击「检查并保存」。即使不使用大模型，你也可以直接用旁白音色完成整书朗读。
- **更换某个角色的音色后需要整书重做吗？**：不需要。系统只会把该角色名下的对白标为待更新，旁白和其他角色已生成的音频会直接复用。
