# 有声书工坊使用指南

「有声书工坊」（快捷键 `⌘5`）让你把一整本中文或双语 `.txt` 小说、非虚构作品或长文稿导入 SpeechRail，在本机完成章节整理、角色识别、多角色配音、逐段返修、沉浸收听与标准 `.m4b` / 分章 `.mp3` 导出。

## 1. 五步完成一本有声书

### 第一步：导入 TXT 书稿

1. 在左侧边栏「创作」分组点击 **有声书工坊**（或按 `⌘5`），点击右上角 **导入 TXT**。
2. 选择本机 `.txt` 文件（支持 UTF-8、UTF-16、GB18030 等常见中文编码，单本上限 64 MiB）。
3. 格式探测完成后，先进入 **整理段落与章节**。系统在本地连接段内的排版折行，保留空行分段、独立对白和诗行，再整理章节目录；这里不会调用 AI。
4. 核对书名、作者、段落和目录。选择章节可查看整理后的正文节选，打开 **查看原始排版** 可与来源对照。目录支持「第X章 / 第X回 / Chapter X / 序章 / 尾声」等显式标题、排版证据充分的独立篇名，以及没有上级篇名时连续编号的小节；中文章号与标题之间可以不留空格。原文缺少开篇标题时显示「开篇」，不猜测作品名称；没有可靠标题则保留为「全文」。
5. 如发现整章正文重复，目录会标出 **内容重复**。核对相应章节后，勾选 **我已核对，保留重复内容继续导入**；系统不会自动删除重复正文。
6. 点击 **确认整理并导入** 进入工作台。原始文件及只读 UTF-8 来源完整保留；连接折行和整理段落仅改变阅读排版，不改写文字、章节来源或历史作品。

合集以独立篇名作为目录层级，作品内部的小章保留在篇内。回目支持“○ / 〇 / 零”章号，也会分离与前后正文粘连的可靠回目。相邻同名标题之间只有空白或分隔线时，共用一个目录入口，两次标题的来源文字仍完整保留。

### 第二步：查看目录与原文

1. 工作台左侧是章节列表，中间分为 **准备与角色**、**制作与返修** 两个页签。选择章节，在 **准备与角色** 中查看只读原文。
2. 使用目录旁的 **整理章节** 菜单修正自动分章结果：**重命名章节…** 只改目录名称；在正文中选中一个段落后，可 **在选中段落前拆分**；选中第二章及之后的章节，可 **与上一章合并**。这些操作不改写导入的原文。
3. 拆分和合并须在开始全书分析之前完成。分析开始或已有音频后，仍可重命名章节；章节范围保持固定，以保留角色标注、候选音频和返修历史。

### 第三步：全书角色梳理与音色试听

1. 在 **准备与角色** 中点击 **分析全书**。系统会基于你在「设置 ▸ 语音助手与 AI」中配置的服务（或「有声书理解」专用配置）分窗分析正文，提取出场角色和声音线索，并把对白归属到对应角色。正文按窗口发送给所选 AI 服务，请按书稿的隐私要求选择服务。
2. 分析是分钟级长任务，工作台顶部会显示确定性进度条：当前步骤（共 3 步）、已处理窗口数、百分比与已用时间；某段较难需要拆小重试、或等待时间超过 1 分钟时，会给出明确提示，已完成的检查点都已保存，可随时暂停稍后继续。
3. 若某句台词上下文模糊，或 AI 漏标直接对白，系统会将其标为 **待确认**，对应章节暂停制作。点击左侧 **快速定位下一处待确认**，在正文旁确认角色或明确选择旁白；其他已确认章节可继续制作。
4. 在 **人物与声音** 中为 **旁白** 和 **主要角色** 选择声音，也可以点击 **推荐声音**。核对将调整的角色、片段及需要确认的共用风险，在 **试听与分配说明** 中比较同一段原文或相邻对白，再点击 **应用配声方案**。试听满意后点击 **确认配声**。窗口较窄时，点击 **人物与声音** 打开面板。

自动配声保留已有选择，只补全尚未选声的角色。没有足够的可制作声音、声音归属不清或角色独占要求冲突时，会保留未完成状态并提示处理，不会借用其他书籍的专用声音或自动允许共用。旧声音参数需要重新确认时，已有音频和章节版本仍保留；重新选择合法声音并试听后再继续。

**撤销上次配声** 可恢复此前的声音选择，也能单独撤回角色的共享开关，保留已采用音频和全部历史候选。声音目录或角色选择已经变化时，请重新推荐或核对，旧方案不会继续应用。试听用于比较声音，不会直接更新章节音频。

本书中新设计或克隆的声音默认仅供本书使用。在音色库中显式 **设为通用声音** 后，才能供其他书籍和配音台选用；归档和恢复保留此范围。收藏只是筛选偏好，不会让其他书籍的专用声音进入当前列表。归属待确认的旧声音需先确认范围，再恢复使用。

### 第四步：章节制作与逐段返修

1. 完成人物与声音确认后，进入 **制作与返修**，点击 **制作已确认章节**。系统根据各章准备状态顺序制作；尚有待确认对白的章节不会进入制作。
2. 工作台顶部持续显示制作阶段、当前章节、已保存片段数、百分比与已用时间，切换「准备与角色」「制作与返修」后仍可查看。准备、核对已有音频、生成、保存、整理章节和服务繁忙重试都有明确状态；当前步骤超过一分钟没有进展时会提示检查服务。书架也会显示正在制作的实时进度。百分比按已保存的片段计算，不代表内容质量或听感验收。
3. 已完成的片段逐个保存。点击 **暂停制作** 后，界面先显示正在暂停，待当前请求停止与本地收尾完成后显示 **继续制作**。关闭应用或重启电脑后，中断任务显示为已暂停；继续会保留上次选择的章节范围，单段重录也只继续原片段，并核查音频、复用已验证的片段。损坏、未完整保存或制作条件变化的片段需要重新生成，正在使用的章节版本与历史候选继续保留。任务记录保存失败时会明确提示存储问题，此时重新打开后的续作范围无法保证；请检查磁盘空间和作品库写入权限，再重新选择制作范围。
4. 需要调整时，在 **准备与角色** 中修改正文的角色归属，或在 **人物与声音** 中更换该角色音色；重新确认配声后点击 **制作/更新本章**。系统只重新制作受影响片段。
5. 已制作章节中，对某段声音不满意时，点击该片段的 **重录本段**，会使用当前配声生成一个新候选，其他片段和当前采用版本保持不变。尚未制作的章节先使用 **制作/更新本章**。
6. 展开 **候选版本对比与采用**，分别试听并点击 **采用此候选**，才会更新正在使用的章节版本。需要恢复时，使用 **回退本章上一版本**。

### 第五步：沉浸收听与导出成书

1. 在顶部切换到 **听书模式**，可按章连续收听，系统记住收听位置与倍速；需要调整时返回工作台修改并更新章节。
2. 点击顶部 **导出…**，选择整本或指定章节，并核对导出预览中的章节与未包含原因：
   - **单文件有声书 (`.m4b`)**：包含章节书签、书名和作者元数据；导出时会读取实际章节标记，核对数量、标题和起止位置，可导入支持该格式的播放器；
   - **分章音频包 (`.mp3`)**：按 `chapter_0001.mp3` 顺序输出独立章节文件与 `chapters-manifest.json` 清单。

## 2. 常见问题与排障

- **提示「未配置可用的大模型服务」**：打开 `⌘,`（设置 ▸ 语音助手与 AI），填写全局服务或「有声书理解」专用配置，点击「检查并保存」，再返回工坊开始全书分析。章节制作需要先完成全书分析；未配置服务时可以导入书稿和查看目录。
- **更换某个角色的音色后需要整书重做吗？**：不需要。系统只会把该角色名下的对白标为待更新，旁白和其他角色已生成的音频会直接复用。
- **已有章节导出时提示音频时长校验失败**：升级前制作的音频可能存在采样信息错误。返回 **制作与返修**，主动点击 **制作/更新本章** 生成新候选；原音频和历史采用版本保留。旧制作策略的章节首次更新可能需要重新生成全部片段，请为长篇作品预留制作时间。
