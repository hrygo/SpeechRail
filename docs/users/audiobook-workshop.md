# 有声书工坊使用指南

「有声书工坊」（快捷键 `⌘5`）让你把一整本中文或双语 `.txt` 小说、非虚构作品或长文稿导入 SpeechRail，在本机完成章节整理、角色识别、多角色配音、逐段返修、沉浸收听与标准 `.m4b` / 分章 `.mp3` 导出。

## 1. 五步完成一本有声书

### 第一步：导入 TXT 或 EPUB 书稿

1. 在左侧边栏「创作」分组点击 **有声书工坊**（或按 `⌘5`），点击右上角 **导入书稿**。
2. 选择本机 `.txt` 文件（支持 UTF-8、UTF-16、GB18030 等常见中文编码，单本上限 64 MiB），或 `.epub` 文件（无 DRM，解压后正文上限 256 MiB）。也可以把 TXT/EPUB 直接拖到书架空白处或书籍列表上。
3. 格式探测完成后，先进入 **整理段落与章节**。系统在本地连接段内的排版折行，保留空行分段、独立对白和诗行，再整理章节目录；这里不会调用 AI。若文件不是 UTF-8、但可无损按 GB18030 解码，或 UTF-8 解码结果含可疑控制符，系统会先按探测结果打开核对页并提示需要确认编码；用上方的 **文件编码** 切换后核对正文即可。
4. 核对书名、作者、段落和目录。选择章节可查看整理后的正文节选，打开 **查看原始排版** 可与来源对照。目录支持「第X章 / 第X回 / Chapter X / 序章 / 尾声」等显式标题、排版证据充分的独立篇名，以及没有上级篇名时连续编号的小节；中文章号与标题之间可以不留空格。原文缺少开篇标题时显示「开篇」，不猜测作品名称；没有可靠标题则保留为「全文」。
5. 如发现整章正文重复，目录会标出 **内容重复**。核对相应章节后，勾选 **我已核对，保留重复内容继续导入**；系统不会自动删除重复正文。
6. 点击 **确认整理并导入** 进入工作台。TXT 的原始文件与只读 UTF-8 来源完整保留；EPUB 只保留转换后的规范纯文本来源，不保存原始压缩包。连接折行和整理段落仅改变阅读排版，不改写文字、章节来源或历史作品。

EPUB 按书内阅读顺序（spine）提取正文和章节标题，转成纯文本后走同一套规范化、分章与重复内容检查；书名/作者从书内元数据读取，可再修改。原始 EPUB、脚本、样式和外部图片都不会保存，也不执行；受 DRM 保护或压缩包结构异常时直接拒绝并说明原因。

合集以独立篇名作为目录层级，作品内部的小章保留在篇内。回目支持“○ / 〇 / 零”章号，也会分离与前后正文粘连的可靠回目。相邻同名标题之间只有空白或分隔线时，共用一个目录入口，两次标题的来源文字仍完整保留。

书稿开头若带目录页（“目录 / 目次 / Contents”后紧跟章名，或同一批章名在后文再次出现），系统会把目录识别为排除区间：目录不会成为章节、不会进入 AI 分析或朗读，原文与字节区间仍完整保留。导入核对页会提示跳过了多少处目录页。

### 第二步：查看目录与原文

1. 工作台左侧是章节列表，中间分为 **准备与角色**、**制作与返修** 两个页签。选择章节，在 **准备与角色** 中查看只读原文。
2. 使用目录旁的 **整理章节** 菜单修正自动分章结果：**重命名章节…** 只改目录名称；在正文中选中一个段落后，可 **在选中段落前拆分**；选中第二章及之后的章节，可 **与上一章合并**。这些操作不改写导入的原文。
3. 拆分和合并须在开始全书分析之前完成。分析开始或已有音频后，仍可重命名章节；章节范围保持固定，以保留角色标注、候选音频和返修历史。
4. 版权页、致谢等不需要朗读的章节，可用 **整理章节 ▸ 跳过本章（不分析、不制作）** 标记为跳过。跳过的章节不进入全书分析、制作和导出，但原文、章节结构和已有确认都保留；在章节列表或正文顶部点击 **恢复本章** 即可重新纳入。

### 第三步：全书角色梳理与音色试听

1. 在 **准备与角色** 中点击 **分析全书**。系统会基于你在「设置 ▸ 语音助手与 AI」中配置的服务（或「有声书理解」专用配置）分窗分析正文，提取出场角色和声音线索，并把对白归属到对应角色。正文按窗口发送给所选 AI 服务，请按书稿的隐私要求选择服务。
2. 分析是分钟级长任务，工作台顶部会显示确定性进度条：当前步骤（共 3 步）、已处理窗口数、百分比与已用时间；某段较难需要拆小重试、或等待时间超过 1 分钟时，会给出明确提示，已完成的检查点都已保存，可随时暂停稍后继续。
3. 若某句台词上下文模糊，或 AI 漏标直接对白，系统会将其标为 **待确认**，对应章节暂停制作。点击左侧 **快速定位下一处待确认**，在正文旁确认角色或明确选择旁白；全部确认完毕后，系统会自动锁定角色与音色并直达章节制作。
4. 点击 **分析全书** 后，系统在分窗分析完成后会自动串行执行 AI 二次消歧、检测并补全六类群像音色、为核心主角生成专属音色，并完成全书智能防撞音预分配。若全书无待确认歧义对白，系统会自动锁定角色与试听摘要，右侧底部主按钮直接自适应变为 **开始制作章节**；点击即可直接进入章节制作。
5. 在 **人物与声音** 中，角色卡片默认采用紧凑视图，点击卡片展开按钮可查看声学画像、原文出处依据、次要角色声线共用开关与专属音色微调入口。底部主按钮根据状态自适应显示为 **一键智能配声** 或 **开始制作章节**；需要更深度整理时，点击 **更多整理…** 菜单可选用 **补全六类群像**、**为主角生成专属音色**、**按声部批量配音…**、**合并/拆分角色…** 及 **撤销上次配声**。窗口较窄时，点击 **人物与声音** 打开面板。

自动配声保留已有选择，只补全尚未选声的角色。没有足够的可制作声音、声音归属不清或角色独占要求冲突时，会保留未完成状态并提示处理，不会借用其他书籍的专用声音或自动允许共用。旧声音参数需要重新确认时，已有音频和章节版本仍保留；重新选择合法声音并试听后再继续。

「更多整理…」中的 **撤销上次配声** 可恢复此前的声音选择，也能单独撤回角色的共享开关，保留已采用音频和全部历史候选。声音目录或角色选择已经变化时，旧方案不会继续应用。试听用于比较声音，不会直接更新章节音频。

本书中新设计或克隆的声音默认仅供本书使用。在音色库中显式 **设为通用声音** 后，才能供其他书籍和配音台选用；归档和恢复保留此范围。收藏只是筛选偏好，不会让其他书籍的专用声音进入当前列表。归属待确认的旧声音需先确认范围，再恢复使用。

### 第四步：章节制作与逐段返修

1. 完成人物与声音确认后，进入 **制作与返修**，点击 **制作已确认章节**。系统根据各章准备状态顺序制作；尚有待确认对白的章节不会进入制作。
2. 工作台顶部持续显示制作阶段、当前章节、已保存片段数、百分比与已用时间，切换「准备与角色」「制作与返修」后仍可查看。准备、核对已有音频、生成、保存、整理章节和服务繁忙重试都有明确状态；当前步骤超过一分钟没有进展时会提示检查服务。书架也会显示正在制作的实时进度。百分比按已保存的片段计算，不代表内容质量或听感验收。
3. 已完成的片段逐个保存。点击 **暂停制作** 后，界面先显示正在暂停，待当前请求停止与本地收尾完成后显示 **继续制作**。关闭应用或重启电脑后，中断任务显示为已暂停；继续会保留上次选择的章节范围，单段重录也只继续原片段，并核查音频、复用已验证的片段。损坏、未完整保存或制作条件变化的片段需要重新生成，正在使用的章节版本与历史候选继续保留。任务记录保存失败时会明确提示存储问题，此时重新打开后的续作范围无法保证；请检查磁盘空间和作品库写入权限，再重新选择制作范围。
4. 需要调整时，在 **准备与角色** 中修改正文的角色归属，或在 **人物与声音** 中更换该角色音色。更换有对白的角色声音前，系统会提示该角色的对白数与涉及章节数；取消不会改变任何绑定，确认后才会标记待更新。重新确认配声后点击章节操作区的 **生成本章音频** 或 **更新本章音频**，系统只重新制作受影响片段，已采用版本与历史候选保留。
5. 已制作章节中，对某段声音不满意时，点击该片段的 **重录本段**，会使用当前配声生成一个新候选，其他片段和当前采用版本保持不变。尚未制作的章节先使用 **生成本章音频**；已有采用版本后用 **更新本章音频**。
6. 展开 **历史重录版本**，分别试听并点击 **采用此候选**，才会更新正在使用的章节版本。需要恢复时，使用 **回退本章上一版本**。
7. 人名、地名或古汉语多音字读错时，点击 **发音规则（N）** 打开本书专用词表，填写原文与期望读法，可限定大小写或整词匹配。保存后只把包含这些词的片段标为待重做，其他已生成片段继续复用；重新制作或重录即可听到新读法。词表按不可变版本保存，若在别处修改过，界面会先要求刷新，避免覆盖较新的版本。

### 第五步：沉浸收听与导出成书

1. 在顶部切换到 **听书模式**，可按章连续收听。播放时时间码随音频实时前进，收听位置每约 5 秒自动写入书签；暂停、切换到角色试听或离开工坊时也会保存当前片内位置，回来后可从未听完的位置继续。倍速与书签一起保留；需要调整内容时返回工作台修改并更新章节。还没有任何成品音频时，听书模式会显示“去制作章节”的引导，而不是空白播放器；已跳过的章节不会出现在可收听列表里。
2. 点击顶部 **导出…**，选择整本或指定章节。导出面板会先显示就绪概览：整本 M4B 要求所有未跳过章节都有当前音频，未齐时按钮不可用并提供“去制作…”直达；分章节 MP3 只允许勾选已就绪章节，默认全选已就绪项。生成或保存失败时，原因会直接显示在面板内，不会藏到被遮住的主页面。随后核对导出预览中的章节与未包含原因：
   - **单文件有声书 (`.m4b`)**：包含章节书签、书名和作者元数据；导出时会读取实际章节标记，核对数量、标题和起止位置，可导入支持该格式的播放器；
   - **分章音频包 (`.mp3`)**：按 `chapter_0001.mp3` 顺序输出独立章节文件与 `chapters-manifest.json` 清单。
   导出准备阶段可点击 **取消导出**；取消后不会生成或覆盖任何文件。保存时若目标位置已有同名文件或同名 MP3 目录，系统会再次明确询问是否整体替换，取消不会改动原内容。跳过章节会列为未包含原因，但不会阻止整本导出。

## 2. 常见问题与排障

- **提示「未配置可用的大模型服务」**：打开 `⌘,`（设置 ▸ 语音助手与 AI），填写全局服务或「有声书理解」专用配置，点击「检查并保存」，再返回工坊开始全书分析。章节制作需要先完成全书分析；未配置服务时可以导入书稿和查看目录。
- **分析失败后重开作品，还能看到原因吗？**：可以。系统会保存低基数错误类型、可行动提示和失败窗口序号（不保存服务错误正文或书稿原文）；书架显示「分析：需重试」，打开作品时顶部横幅给出下一步建议。已完成的窗口和检查点不会丢失。
- **跳过的章节会出现在导出里吗？**：不会。跳过章节不参与分析和制作，导出预览会把它列为未包含并说明「已按你的设置跳过」；整本 M4B 不会因为它阻塞。恢复章节后可重新分析与制作。
- **更换某个角色的音色后需要整书重做吗？**：不需要。系统只会把该角色名下的对白标为待更新，旁白和其他角色已生成的音频会直接复用。换声前的确认会给出该角色的对白数与涉及章节数，便于判断重做范围。
- **误把书移进废纸篓了怎么办？**：书架顶部会出现“已移入废纸篓”横幅，直接点 **撤销** 即可恢复刚移走的那一本；也可以打开 **废纸篓** 选择任意作品恢复。恢复会带回章节、分析、角色和已生成音频，不影响原始书稿与已导出的外部文件。
- **已有章节导出时提示音频时长校验失败**：升级前制作的音频可能存在采样信息错误。返回 **制作与返修**，主动点击 **制作/更新本章** 生成新候选；原音频和历史采用版本保留。旧制作策略的章节首次更新可能需要重新生成全部片段，请为长篇作品预留制作时间。
