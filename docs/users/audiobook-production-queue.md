# 有声书制作队列使用指南

「制作队列」让你把**多本已确认制作范围的有声书**排成一队，App 依次制作，你可以离开工坊去做别的事。它位于有声书工坊的「制作与返修」页，在制作条件检查条下方。

队列遵循三条硬规则：

- **一次只制作一项。** 前一本书真正收尾后，下一本才开始；两本书不会同时占用语音服务。
- **失败就停，等你处理。** 任何一项失败，队列停在该项上，不会跳过它继续做后面的书。
- **重启不自动续跑。** App 退出前还没确认终态的项，下次打开会标为「待核对」，需要你核对后才会继续。

## 1. 把一本书加入队列

1. 在有声书工坊中打开一本书，进入「制作与返修」页，像往常一样选择制作范围（只补缺失音频或更新选定片段），打开制作确认面板。
2. 面板底部有两个并列按钮：**确认制作** 与 **加入制作队列**。
   - **确认制作**：立即开始制作这一本，行为与没有队列时完全一致。
   - **加入制作队列**：把这份已确认的范围排进队列，不打断你当前正在看或正在做的其他事。
3. 点击「加入制作队列」后，面板关闭，制作页出现「制作队列」面板，新入队的书显示为「等待中」。

入队时 App 会核对当前作品、文本版本和制作范围是否仍然有效；范围已变化或没有需要处理的片段时，会说明原因并请你重新预览。同一本书同时只占队列中的一个位置：已在进行、等待中、已暂停或待核对的项不能重复入队；已完成的项可以带着新的制作范围再次入队。

## 2. 队列怎么排

- 队列按**入队顺序**执行。对还未开始的项，点击该项右侧的 **上移** / **下移** 可调整顺序；正在制作、已暂停和待核对的项不能移动。
- 每项显示书名、状态和（如有）失败原因。状态包括：等待中、正在制作、等待语音服务、已暂停、失败、已完成、待核对。
- 点击未开始项的 **取消** 直接把它移出队列；取消正在制作的项会请求停止，已保存的音频和历史版本全部保留，该项从队列移除。

## 3. 失败与重试

- 一项失败时，队列停在该项上，后面的书不会开始。失败原因显示在该项旁边。
- 点击队列标题右侧的 **重试失败项**，所有失败项按原顺序重新入队。重试会接着上一次的进度继续：已经成功提交的片段不会重复制作。
- 修好失败原因（例如在「设置」里换可用的语音服务配置）后再重试；原因不明时，失败原因文本是第一条线索。

## 4. 暂停与继续

- 点击 **暂停队列**，正在制作的项会等当前片段收尾后停下，整队标为「已暂停」。暂停不会丢弃已保存的音频。
- 点击 **继续队列** 从下一项继续。暂停期间入队的新书会排在队尾。

## 5. 重启后的「待核对」项

App 退出时还没确认终态的项（正在制作或等待语音服务），下次打开会标为 **待核对**，队列不会自动继续——因为中断时的远端状态需要你先核对。核对已保存的音频后，点击该项的 **核对后继续**，该项回到队列原位置等待执行。

## 6. 边界与事实

- 队列只调度**已确认的制作范围**，不代替你预览和确认；每次入队的范围以确认面板上显示的章节与片段数为准。
- 队列记录保存在本机单一文件；读取失败时页面会明确提示，已入队的内容在本次运行中仍会执行，但重启后可能丢失。
- 队列不改变制作条件，不跳过失败项，也不把「用户取消」记成「已完成」。
- 与「确认制作」一样，队列中的制作遵守既有的章节跳过、待确认对白和音色约束；不满足条件时会在入队前或执行时给出可读原因。
