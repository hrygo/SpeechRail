# 有声书工坊流程、算法与用户旅程审查记录

本记录覆盖 TXT 导入、章节规划、全书分析、角色确认、章节制作、返修恢复、收听和导出。证据来自当前源码、公共行为文档、定向 fake / 合成音频回归及隔离 App 编译；前台 UI、真实模型质量、真实性能和长时稳定性不在本次实测范围内。

用户授权直接按审查结果实施优化。修改沿用现有 SwiftUI、WorkflowModel 和控制器边界，不改变服务公共 API、持久化格式、用户数据库、模型、安装或运行态。

## 1. 发现与处理

| 优先级 | 触发与影响 | 修复边界 | 验证状态 |

| P1 | 服务返回 24 kHz WAV，原样落盘却标为 48 kHz，时长减半且无法通过独立导出校验 | 原始 PCM 核验回执后真正重采样；按转换产物计算帧数和摘要；限制转换内存；渲染策略升级 v2 | 合成 24 kHz 输入及旧候选复用回归通过 |
| P1 | prepare 不比较编码回执摘要，commit 信任缓存校验；stage 可在准备后被替换 | 校验精确输出清单、独立预期帧数与媒体摘要；目标旁临时副本复核 prepare 摘要后原子提交 | 已复现 RED；纳入模块回归 |

## 4. 未验证范围与恢复

没有运行前台 UI 自动化、真实 LLM / TTS、音质基准、长篇真实制作或安装验收。定向 fake 回归通过只能证明被断言的流程和边界，不能替代这些验证。

后续仍需处理的产品/验收缺口：

- M4B 实际章节标记未被独立读取；当前只验证音轨、codec、时长及文件完整性，不能把投影的章节标题视为容器章节验证。
- 崩溃恢复保护资产与候选，但未归一化上次进程留下的书籍 `.running` 状态。恢复逻辑应区别活动任务和历史状态后另行补充，避免每次书架刷新干扰后台制作。
- 章节拆分/合并/重命名与独立单段重录目前没有界面入口；指南不再承诺这些入口。

策略影响：旧 v1 分析检查点在下次主动分析时重新计算；旧 v1 渲染候选在下次主动制作时生成新策略候选，以避免继续复用采样率错误的音频。旧资产和历史采用版本保留，没有批量处理真实书籍。

本任务改动保留为未提交差异；本任务没有操作真实书籍、音频、配置、模型、服务或正式安装。恢复时仅逆向本记录列出的本次差异，先核对并行修改；不得整文件还原或重置工作区。

审查期间保留了独立并行提交 `e655228e`（版本发布材料）和 `061d32e8`（已有轮廓 API 编译修正）；本任务没有覆盖这些改动。

工作台文件另出现人物卡片、音色选择器布局/hover 的并行差异；用户已确认来自另一任务，要求保留并纳入编译。Debug 构建覆盖共享工作树中的这些差异；它们不归为本次代理实现，编译通过也不表示视觉验收通过。
