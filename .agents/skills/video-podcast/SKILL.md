# 视频播客制作与返修

把用户的资料、口播或访谈制作成可播放、可复查、可局部重建的视频。观众应容易听懂、看懂，并自然地跟随叙事。保留真实表达的重音、情绪、呼吸和有意义的停顿。

## 先选入口，只读相关指南

从当前文件和对话获取：受众、主题、来源、已有定稿、交付平台、画幅、时长约束、语言、声音来源、视觉资产、交付路径。缺少的信息能合理推断时写明假设并继续；只询问确实改变内容或授权的缺口。

先定位用户需要的新产物或待修复时间码，再按下表进入。完整制作按依赖顺序推进；局部返修保留已验收的内容、声音和设计，不要求重新建立全套简报。

| 输入 / 请求 | 首先阅读 | 工作重点 |
| --- | --- | --- |
| 文稿、资料、产品或人物故事 | [production.md](references/production.md) | 事实来源、口播、发音表、时长预算 |
| 单人录音、多人访谈或已有视频再剪辑 | [production.md](references/production.md) 与 [pipeline.md](references/pipeline.md) | 保留原声与原意、源轨对齐、章节和时间映射 |
| 发音、响度、噪声、BGM 问题 | [audio.md](references/audio.md) | 比较源轨与成片，定位后修对应片段 |
| 字幕、同步、尾部空白、缓存问题 | [pipeline.md](references/pipeline.md) | 用实测音频区间修正共同时间轴和依赖 |
| 封面、布局、转场、二维码问题 | [visuals.md](references/visuals.md) | 受影响场景与相邻转场的视觉回归 |

默认在用户指定位置或独立制作目录工作；遵循项目对仓库外素材的要求，保留源素材和已验收版本。先检查所需的 TTS、ASR、图像生成、字体、编码与播放能力，不能假定 SpeechRail、某个音色或收费服务可用。使用已授权工具；服务失败时保留断点并推进独立环节，不擅自部署、下载模型或切换配置。生成图片用当前环境的图像生成能力；缺失时复用授权素材或做排版型视觉，并说明采用的方式。

## 完整制作的阶段出口

每阶段满足出口条件后进入下一阶段；已完成的阶段直接复用。代表性短样片用于尽早发现返工点，不构成新增审批要求。

1. **内容可制作**：事实来源、正式口播、屏幕文案与制作备注分开；保留用户定稿、采访原意和上下文。建立发音表，区分 `spoken_text` 与显示 / 字幕写法。时长预算包含转场和尾页，长节目先分章。具体方法见 [production.md](references/production.md)。
2. **声音可用**：先检查代表性片段，再扩展全片；源缺陷、剪切、段间音量、背景声和母带按需处理，保留自然重音、情绪与呼吸。以实测时长更新预算。见 [audio.md](references/audio.md)。
3. **时间轴一致**：音频剪辑后的实测区间驱动字幕、说话人状态、场景与尾页；明确源时间与成片时间，允许有意的多人重叠。缓存记录输入与生成参数，修改后重建依赖产物。见 [pipeline.md](references/pipeline.md)；新项目可选用 [episode.template.json](assets/episode.template.json)，它是字段模板，不是渲染器。
4. **画面可读**：先验证封面、最长正文、相关说话人状态与尾页样张，再播放短过渡。正式文字用可控排版绘制；分别控制字幕、人物、装饰和场景可见性。BGM、CTA、二维码与音色展示按内容选用。见 [visuals.md](references/visuals.md)。
5. **成片可交付**：先短样片，再最终编码；验收绑定最终文件哈希。全文转录差异检查、风险词回听、字幕与画面复检按 [acceptance.md](references/acceptance.md) 执行。无法听音、转写或试扫时留下未验证项，不用技术数值代替内容 / 感知验收。

## 技术检查入口

使用随附的 [inspect_media.py](scripts/inspect_media.py)；它需要 Python 3.12+、`ffprobe`，响度检查另需 `ffmpeg`。从项目根目录执行以下示例；迁移 skill 后按实际位置设置 `SKILL_DIR`：

```bash
SKILL_DIR=".agents/skills/video-podcast"
uv run python "$SKILL_DIR/scripts/inspect_media.py" path/to/final.mp4 --loudness
```

其他环境可使用已确认的 Python 3.12+ 解释器代替 `uv run python`。先选交付目标，再添加阈值；参数、退出码和完整解码方法见 [acceptance.md](references/acceptance.md)。检查器不验证时间轴清单、发音、画面或主观听感，退出码 0 不代表整体验收通过。

## 局部返修

定位时间码 → 比较源素材与成片 → 修复最早出错阶段 → 重建依赖 → 复检受影响区间及相邻切点。音频变化重测最终音轨，时长变化重算时间映射；仅改颜色 / 位置保留配音缓存。长空档先区分叙事停顿与缺失素材，不自动删除或填随机内容。详细诊断按入口表读取。

## 本项目经验的使用边界

需要追溯蒸馏来源时读 [project-lessons.md](references/project-lessons.md)。本 skill 提炼了实际返修经验，并补充可移植的制作规则；SpeechRail 自传中的 90 秒、9 个总音色、6 个尾部音色、科技粒子和 GitHub 尾页均不构成通用要求。

## 交付

提供可打开的本地成片链接、画幅 / 实际时长、改动、已验证范围与未验证项；准确标注草稿、局部修复或最终版。保留可局部重建所需的音频、字幕、清单和渲染配置；按用户要求附源文件。验收记录绑定该文件哈希，生成成片不自动包含上传发布。
