# 时间轴、渲染与增量构建

## 单一时间基准

制作清单可用 [episode.template.json](../assets/episode.template.json)。模板描述数据约定，实际制作时实现适合项目的读取和验证逻辑；随附媒体检查器不读取此模板。

- `segments` 描述口播或原声：稳定 ID、说话人 / voice、语言、显示 / 口播 / 字幕文本、音频来源、源区间、成片区间、处理参数。
- `scenes` 描述视觉：起止、对应片段、布局、资产、进出场方式。章节、封面和尾页均使用同一时间轴。
- `delivery` 定义画幅、帧率、时长策略、音频格式；`audio` 定义选定的混音目标，未选定保持 `null`。
- `review` 记录已验收版本和待查问题，不能把自动测量字段用作人工确认。

成片区间统一为半开区间 `[start, end)`。采用整数音频采样点或足够精度的秒数存储，最后再转成 SRT 毫秒；不要在每段累加时反复取整。

帧时间为 `frame_index / fps`；采样位置直接计算 `round(frame_index * sample_rate / fps)`，不能反复加 `int(sample_rate / fps)`，后者在分数帧率或不能整除时会积累漂移。`30000/1001` 等帧率保留有理数表示。

明确所有时间映射：裁剪、拼接、调速、滤镜延迟。对已有多人录音，先对齐采样率、起点和设备时钟漂移，再剪辑；长录音检查多个锚点而不只对齐开头。

## 时间轴检查

- ID 唯一；数值有限；区间长度大于零；素材存在且可解码。
- 源区间不超过源文件；成片区间不超过交付时长；调速后的长度与实测一致。
- 同一串行语音轨上的未声明重叠报错。访谈重叠、音乐铺底和转场重叠允许明确表示。
- 统计无语音间隔并按章节停顿、思考、音乐桥、阅读或未知分类。时长阈值只产生复检候选，不自动删除。
- SRT / VTT 与烧录字幕从相同 cue 数据生成；长语句分为可读的短 cue，优先利用词 / 字级对齐，不把整段同时挂屏。
- 说话人卡片、当前播放指示和字幕是不同状态，短暂停顿不应让整个页面闪回空闲。

## 产物与缓存

推荐拆分可独立替换的阶段：内容 → 音频 → 时间轴 / 字幕 → 混音 → 可视化数据 → 画面 → 编码 → 验收。BGM 可与配音独立准备，依赖关系需要在 Makefile / 工作流里显式表达，避免并行执行读取半成品。

TTS 缓存键至少涵盖口播文本、provider、模型 / 版本、voice、语言、风格、语速、输出格式及影响生成的其他参数。验证实际可解码、时长合理，再原子发布到缓存；不能只看文件存在或体积。

| 改动 | 必须重新验证 / 生成 |
| --- | --- |
| 口播 / 发音 / voice / 模型 | 对应原声 → 处理与对齐 → 时间轴 → 母带 → 受影响视觉 → 成片 |
| 增益 / BGM / 压缩 / 调速 | 受影响音频 → 母带；若时长变动则更新全部时间映射 |
| 母带更改 | 基于母带的频谱 / 包络 → 对应帧 → 编码 → 最终测量 |
| 仅标题 / 色彩 / 布局 | 受影响画面 → 编码 → 视觉回归，保留音频缓存 |
| QR URL | QR 资产 / 尾页 → 最终编码帧上的解码验证 |

有声波或频谱时声明分析源是人声 stem 还是混音母带。更改该源必须失效分析缓存；可视化应匹配声明的音轨。使用固定随机种子和由时间驱动的动画，保证抽帧与完整渲染一致。

## 可移植实施

- 路径相对于制作目录 / 清单，不写入本机账户、缓存目录或固定字体路径；中文和多语种字体显式配置并验证字形。
- 音频、生成帧、模型、密钥和临时报告按项目规则放在运行目录或仓库外，不作为 skill 资源提交。
- provider endpoint、voice 和凭据读取由适配器负责。凭据来自授权的环境 / 安全配置，不记入 prompt、命令参数、清单、缓存键或日志。
- 不因服务失败擅自启动、重装或切换模型。有限重试；无法继续时保留断点并报告具体缺项。
- 长节目按章节或镜头渲染，使用流式输出 / 有界缓存，避免把全部高清帧驻留内存。可先生成低分辨率预览，但验收还需检查交付分辨率。
- 拼接时统一 codec、time base、尺寸、像素格式、音频布局；不满足条件则重新编码，不能盲目 stream copy。
- 保留上一可用成片，生成候选文件，验证后再切换交付入口。生成本地视频不触发发布或上传。
