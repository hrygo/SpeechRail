# 成片验收与交付

所有结论绑定一个最终文件版本。验收记录至少有文件哈希、生成 / 检查时间、交付目标、技术实测、复检范围、问题与未验证项；报告只保留必要片段 ID / 时间码，不默认附全量转写或私人素材。

## 分层验收

| 层次 | 检查对象与方法 | 能得出的结论 |
| --- | --- | --- |
| 数据 | 所有剪辑区间、字幕 cue、场景、人物状态与依赖版本 | 没有已发现的越界、意外重叠、陈旧缓存 |
| 技术 | 最终容器、实际流、解码、音视频起止、选定响度目标 | 媒体可解码、元数据与数值满足已检查条件 |
| 内容 | 全文转录对照，风险词逐项回听，画面文字核对 | 已核查的口播与事实 / 字幕一致 |
| 感知 | 播放成片，检查过渡、停顿、声源交接、BGM、字幕、扫码 | 已覆盖范围的听感与视觉表现可接受 |

元数据起止相同只能说明容器区间相符，不能证明口型或字幕同步。静态帧不能证明转场顺滑；ASR 相似度不能证明语义无误；LRA 不能证明局部响度自然。

## 自动检查工具

`.agents/skills/video-podcast/scripts/inspect_media.py` 需要 Python 3.12+、`ffprobe`，使用 `--loudness` 时还需要 `ffmpeg`。只读本地媒体，结果打印为 JSON，不修改视频。默认检查首个非封面视频流与首个音频流；多音轨交付可用 `--video-index` / `--audio-index` 指定 ffprobe 的全局 stream index，不能由默认首轨推断全部音轨合格。

```bash
SKILL_DIR=".agents/skills/video-podcast"
python3 "$SKILL_DIR/scripts/inspect_media.py" final.mp4 --loudness
```

可选 `--expected-duration`、`--duration-tolerance`、`--target-lufs`、`--lufs-tolerance`、`--max-true-peak`、`--av-tolerance`、`--video-index` 与 `--audio-index`。`--timeout` 为单个外部命令上限，长节目可按实际资源调整。选目标阈值时遵循 [audio.md](audio.md)。

退出码：`0` 表示已请求检查无失败且无未知；`1` 表示存在技术失败；`2` 表示数据不足或操作失败。JSON 始终标记 `human_review_required`，不输出“整体验收通过”。未请求响度时不推断响度合格；没有流时长时保留未知，不能用容器时长填入音视频流并制造相等。

无 `--loudness` 时主要读取头部信息；开启后解码完整首个音频流，不执行完整视频逐帧解码。需要检查视频损坏时另用 FFmpeg 全解码：

```bash
ffmpeg -v error -xerror -i final.mp4 -map 0:v:0 -map 0:a:0 -f null -
```

## 全文与同步

从最终媒体抽取音频再 ASR，对照剪辑后的 `spoken_text` / 原录音转写。按片段报告缺失、重复、可疑数字 / 否定词 / 专名、语言切换与时间偏移。处理标点 / 大小写差异，但不能把真正的语义差异规范化掉。

独立 ASR 能减少与 TTS 共享偏差；没有独立服务仍可使用已有能力并标注。短音色 / 外语片段低分先回听，不能为提升分数把正确内容改错。转写服务不可用时保留阻塞的验收项，不冒充已经全文复检。

检查字幕 cue 的开始、结束和可读速度；首、中、尾多个锚点用于查累计漂移。对有人物口型的视频检查爆破音等可见锚点；轻微容器误差与主观延迟分开处理。

## 感知覆盖

短片完整播放至少一遍。长节目全文转录复检，覆盖每个章节、所有自动标记异常、全部编辑切点和说话人交接；如果不能完成全程试听，报告实际覆盖区间和剩余范围，不能称为全片听感验收。

优先覆盖：封面与首句、最长字幕、密集内容、轻声与激昂段、不同声源交接、所有转场、长无语音区间、最后一句、尾页首次完整显示与结束。固定相同播放音量试听，并在可用条件下比较耳机与普通扬声器；没有设备条件时不虚构测试。

视觉检查实际成片帧而不是仅检查画布源图。确认无顶端草稿、缺字、越界、字幕重影、装饰遮挡、尾页闪回。存在 QR 时解码成片中的 QR，并实际试扫或标注未试扫。

## 回归与交付

失败回到最早出错的阶段，保留前后对照，不对所有环节反复加效果。改音频后重测最终音轨；改布局后检查受影响镜头和转场；发布前重新确认提供链接的正是验收版本。

交付成片链接、画幅 / 时长、关键改进、实际验证范围与未验证事项。用户要求时附字幕、音频母带、制作清单和可运行项目。只完成了元数据检测时如实说“技术检查”，不声称发音正确或听感自然。
