# 视觉、节奏与状态

## 用内容建立设计系统

提取用户品牌中的语义色、字体层级、间距、圆角、线宽和动画节奏；没有品牌时建立小型可配置 token 集。科技、温暖、新闻、文化、教育都可以成立，不默认霓虹和 HUD。

为画面定义主次：核心人物 / 图表 / 标题 → 当前语音字幕 → 上下文 → 装饰。每个镜头只保留明确的注意力焦点。按目标画幅重新排版；横屏卡片不是裁掉两边即可变成竖屏。

安全区按平台遮挡和实际播放尺寸检查。长标题换行、最长音色名、数字、外语和中文标点都要取样；缺字先修字体，不用虚构字幕替代用户需要的语言内容。合法的双语字幕或译文应明确标注。

## 封面

用短时间可读的主标题、身份 / 栏目提示和一个视觉主体形成记忆点。人物比例让位于信息密度；保留真人神韵可以靠轮廓、眼镜、发型和神态，不必大头占满画面。

图像生成负责插画与背景，准确标题和标识通过排版层绘制。生成前查看用户原图；从生成素材中检查误生成文字，再隔离正式标题层。不要把调试标签、制作备注、隐藏 HUD 或 prompt 文本绘入正式画面。

封面阅读时间由标题复杂度和节奏决定；短片约 2–4 秒可作试验起点，长节目不必复用同一开头。首句与封面关系应设计清楚，防止观众同时读长标题又听全新密集信息。

## 动效的注意力预算

先用构图、层次和清晰变化达到吸引力，再加入少量有意义的动效。正文期间降低背景亮度、速度、密度和运动面积；字幕区域避免粒子穿越。频谱用平滑包络、幅度上限和缓变衰减，不能每帧抖动。

动画强度是联合效果，不是粒子数量一个变量。把视频缩到手机大小并静音观看：如果目光总被装饰拉走，降低它们；再播放检查动作是否和语音节拍一致。长节目减少持续刺激，使用稳定布局与章节变化，不延长短广告式全屏动效。

## 转场与语音切换

时间轴同时驱动场景进出、旧字幕消失、新内容显现和状态高亮。内容密集的两页直接透明叠化容易让文字重影，优先试用遮罩揭示、推移或先退旧文再进新文。

转场使用连续速度曲线，控制视觉方向与叙事方向一致。音频衔接可以提前 / 延后画面切换，但必须是设计好的 J-cut / L-cut；不要自动给任何不同说话人的词头词尾做交叉混合。

保留人物卡片跨越自然短间隙，字幕则按真实发声区间显示；新说话人发声前不能提前亮“正在说话”。真实双人重叠需要可见的双状态或合理构图。

抽查转场前一帧、25%、50%、75%、后一帧，并播放整个过渡。单张中间帧不能证明运动流畅。

## QR 与尾页

仅在用户意图中需要时加入。URL 由用户或项目事实确定；显示文字、编码内容和实际解码结果要一致。

QR 四周保留至少四个模块的纯净留白，装饰框不进入此区。[DENSO WAVE：QR 留白要求](https://www.qrcode.com/en/howto/code.html)

整数像素绘制模块，在完整二维码外计算卡片中心。尽量原生目标尺寸输出，避免任意缩放和模糊插值。卡片对齐、二维码对齐、文字光学居中分别检查。QR 稳定可见，不随节拍缩放、旋转或呼吸。

尾页音乐 / 音色可以活动，QR 保持安静；给观众足够识别、拿手机和扫码的时间，短片剩余时长不足时缩减其他内容或说明需要延长。解码最终编码抽帧并在目标显示尺寸下试扫；“看起来整齐”不等于可扫码。
