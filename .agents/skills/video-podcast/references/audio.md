# 自然响度与混音

目标是消除非自然的不适，保留说话者的重音、激昂、轻声、呼吸和有意义的停顿。先定位原因再处理，不把“整片 LUFS 合格”当作“每个切点都舒服”。

## 先区分问题

| 听感 / 证据 | 优先处理 | 防止误治 |
| --- | --- | --- |
| 同声源不同录音片段电平跳变 | 对可比语句测量并做有界 clip gain / 增益自动化 | 不按每句话强制同 LUFS |
| 换人 / 换 TTS 音色突然变响 | 代表性连续语音匹配，再听相邻交接 | 音色、频谱与响度不同，不能仅看峰值 |
| 单段内部有异常爆点 | 局部自动化、修复；必要时温和压缩 | 不用全片重压缩掩盖一个爆点 |
| 原始音频已削波、错读或断句 | 修复或重录 / 重生成对应片段 | 限幅和字幕不能恢复丢失内容 |
| BGM 刺耳、抢字 | 降床音、频谱避让、减少瞬态，再做 ducking | 换一首歌后旧的 `volume` 系数不可直接复用 |
| 呼吸时音乐突起、泵动 | 延长恢复或用语音区间平滑自动化 | 强门限会切掉轻声与呼吸 |

## 推荐顺序

源轨检查 / 对齐 → 剪辑与短淡入淡出 → 必要降噪、去爆破 / 齿音 → 可比语音电平匹配 → 必要的温和动态控制 → 背景声和旁链避让 → 母带响度 → 编码后再测量与试听。

不要机械加全套效果；源声音已良好时跳过修复步骤。保留原轨用于 A/B，使用相同播放音量比较。

有界片段校正可以用：

```text
gain_db = clamp((reference_lufs - measured_lufs) * strength, -limit_db, limit_db)
```

`reference_lufs` 应来自相近语气、可比长度的语音片段，而非直接用母带目标。普通叙述可先尝试较弱校正；明显异源差异再增强。短音色展示可更积极，但这是编辑判断，不是固定标准。极短、静音、门控未通过片段的 LUFS / LRA 可能不可靠；`inf`、`NaN` 或不可测值不得进入增益计算。延长取样、汇总同声源语音并结合耳听。

段内需要压缩时保留起音与自然释放，关注抽吸、齿音突出和噪声抬升。只因数值离散就逐字拉平会损害表达。噪声门与静音删除不能代替语义剪辑。

## 背景声

先在人声真实音量下配床音。纯访谈或情绪叙事可以无 BGM。音乐与语音争夺注意力时先降低、简化或换素材；按实际频谱决定 EQ，不强制某个高低通频率。

旁链让语音控制 BGM，而非反向。attack 应保护句首，release 应跨过短呼吸但不长时间压住章节间音乐；依据语速和素材调节。避免循环点、重复短促“biu”声和硬切。音色演示时进一步压低伴奏，确保观众实际听见差异。

## 选定交付目标

按平台官方规范优先。目标需说明是广播母版、在线分发还是特定播客平台，并记录声道布局。

EBU R 128 s2 仍以广播节目 `-23 LUFS` 为基准，在其规定条件下允许流媒体分发采用 `-20` 至 `-16 LUFS`；它不是所有视频网站的统一指标。[EBU R 128 s2（2023）](https://tech.ebu.ch/docs/r/r128s2.pdf)

平台未明确时，立体声、语音为主、面向日常设备的视频可将 `-16 LUFS`、编码前真峰值预留约 `-1.5` 至 `-2 dBTP` 作为制作起点，再听和测。它们是编辑默认值，不能宣称官方强制标准；编码后的上限另行选择。单声道 / dual-mono、音乐占比高、戏剧性或多声道内容需要重新判断，不能生搬相同数值。

整体响度 I、真峰值 TP、响度范围 LRA 与可比语音区间的短时 / 瞬时变化一起看。LRA 描述宏观变化，不等于峰均比，也不能证明短语之间没有跳变。短片或极短语句的 LRA 尤其不宜作为唯一依据。

## 双遍处理与复检

先导出固定的预母带，保证两遍测量的剪辑、增益、采样和时长完全一致。第一遍测量记录 `input_i`、`input_tp`、`input_lra`、`input_thresh`、`target_offset`；第二遍分别传给 `measured_I`、`measured_TP`、`measured_LRA`、`measured_thresh`、`offset`，并使用相同目标。

`linear=true` 是请求：当源 LRA / 增益后峰值不满足条件时 FFmpeg 可退回动态模式。检查实际模式，不能声称使用该参数就保留了所有动态；明确输出采样率。[FFmpeg loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)

对最终 AAC / Opus 解码结果重新测量，因为有损编码可能改变峰值。未满足目标则调整预留量后重新导出；不要只引用母带 WAV 数值。需要进一步排查时测切换点前后可比语音，避免把 BGM 或不同长度的静音纳入后误判。每次最终音频变动都会使依赖它的频谱和验收失效。
