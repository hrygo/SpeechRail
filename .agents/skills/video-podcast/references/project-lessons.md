# 蒸馏来源与推广边界

来源：SpeechRail `examples/autobiography-video/` 的实际代码、示例文档与本次用户返修反馈；核对日期 2026-09-06。本表给出可在本仓库搜索的路径 / 符号；迁到其他仓库时不依赖源项目运行。

| 证据 / 反馈 | 提炼规则 | 不继承的项目常量 |
| --- | --- | --- |
| `01_generate_voiceover.py` 的 `spoken_text`，用户指出 17–20 秒发音不对 | 屏幕写法与口播写法分开；音频复检后交付 | `1:1` 台词、特定 provider / voice |
| `synthesize_audio` 的 voice + 文本哈希 | 改词必须失效音频缓存；通用版扩大到完整生成参数并验证可解码 | 原实现仅检查体积及存在，不作为足够验证 |
| `03_process_audio_and_mix.py` 的分段测量、有界增益、双遍母带 | 修正非自然跳变，保留人类语气；母带与局部交接都要检查 | 固定 `±1.5 dB`、`-16 LUFS`、BGM `0.14` 不作为通用规范 |
| 用户多次要求动效克制且专业 | 动效占用注意力，强度跟随场景与信息密度 | 科技离子、36 个节点、青色 / 琥珀色 |
| `05_render_video.py` 独立封面 / 正文 / 尾页及遮罩转场 | 正式文字与制作备注隔离，防止旧层穿透和文字重影 | 固定 3 秒封面、1 秒 wipe |
| 用户指出 70 秒空白与尾部剩余时长 | 用实际声音推动时间轴，分类检查空档与结尾 | 第 70 秒、第 81.2 秒的硬编码切点 |
| `get_current_showcase_voice` 保持间歇卡片 | 显示上下文与发声活动分开，避免短间隙闪烁 | 固定 180ms 间隔和 2×3 矩阵 |
| 全片总音色与尾部新增音色的需求 | 集合差决定尚未展示项，交付描述区分总数与新增数 | 9 种总音色中尾部为 6 种，不是尾部 9 种 |
| QR 对齐反复精修 | 视觉对齐与实际可扫码均需要验收 | GitHub URL、300px 方框 |
| `04_analyze_waveform.py` 根据音频生成逐帧频谱 | 分析源变化必须重建频谱；时间换算避免分数帧率漂移 | 64 bands、30fps、2700 帧和 PCM16 假设 |
| `Makefile` 的 mix / spectrum / video 依赖 | 明确依赖图，避免阶段抢读旧产物 | 固定五个脚本与系统字体 |

这是对成功做法和返修暴露问题的综合提炼，不是源实现已满足全部通用规则的声明。例如分数帧率、多源长录音漂移和完整缓存键属于通用化补充，需要在使用时实现并验证。

## 使用场景复演

用以下场景检查技能是否仍保留正确边界。它们是评估输入与预期行为，不是已执行的独立模型盲测记录。

| 请求 | 应有行为 |
| --- | --- |
| “把这篇科普稿做成 4 分钟竖屏视频” | 拆节拍、验证事实 / 发音、按竖屏排版；不固定 90 秒和科技背景 |
| “将 45 分钟双人录音做成视频播客” | 保留原声与真实互动，源轨对齐、章节、全文转录；不自动改成 TTS |
| “只修这支片在 02:13 换人时突然变响” | 查局部声源 / 混音，保留表演情绪，重测最终交接；不重做所有设计 |
| “有情绪起伏，但别把它们压平” | 将自然表达与剪切 / 声源缺陷分开判断，避免逐句强制同响度 |
| “做科技风但专业，声音是主角” | 通过版式和连续运动增强，正文动效克制；不用高亮粒子堆数量 |
| “仅导出这段录音的文字” | 使用转写能力，不启动整套视频制作 |
| “我只要二维码向右移动 8px” | 仅改尾页并回归扫码 / 转场，不重新生成配音 |
| “服务不可用，先把可做的完成” | 完成脚本、设计和数据结构并保留缺失项，不私自部署模型，不造验收 |

复杂度增加时在临时制作目录进行实际试制；具备且获得委派授权时可独立评估。没有独立测试就不声称通用制作行为已实测覆盖。
